Toutes vos données sont stockées exclusivement sur votre appareil. Nous n'avons pas de serveurs cloud, de comptes utilisateur ou de moyen d'accéder à vos documents. Lorsque vous enregistrez un document, il reste dans la zone de stockage sécurisée de votre téléphone.

Vos données restent chiffrées dans ces sauvegardes. Ce processus est géré par votre système d'exploitation, pas par nous.

Fonctionnalités

L'application supporte les Passeports, les Pièces d'identité nationales (recto + verso), les Visas/Permis de résidence, les Billets d'avion, les Bons d'achat et Billets d'entrée (cartes-cadeaux, codes promo, billets d'événement, avec rappels d'expiration afin qu'ils ne s'évanouissent pas), les Autres documents (assurance voyage, assurance maladie, dossiers de vaccination, adhésions, ordonnances, quoi que ce soit avec une date d'expiration), et les Notes (texte uniquement pour les délais et rappels). Vous pouvez capturer les documents à l'aide de votre appareil photo, importer à partir de votre photothèque ou importer des fichiers PDF. Les utilisateurs Pro peuvent capturer les documents multi-pages pour les billets d'avion, les bons d'achat et les autres documents.

Nous envoyons des rappels en cascade commençant 6 mois avant l'expiration pour les passeports (le renouvellement des passeports prend 6-8 semaines), puis à 3 mois, 6 semaines, 1 mois, 2 semaines, 1 semaine, 2 jours et 1 jour. Même si vous manquez la date limite, nous vous rappellerons le jour suivant et une semaine après l'expiration pour vous aider à démarrer le processus de renouvellement. Les billets d'avion reçoivent des rappels finaux plus fréquents (1 semaine, 2 jours, 1 jour, 24 heures) mais aucun rappel post-expiration puisque le vol a décollé.

L'OCR (Reconnaissance optique de caractères) détecte automatiquement les dates d'expiration de vos documents. Pointez votre appareil photo vers un document et l'application essaiera de lire la date d'expiration. Tout le traitement se fait sur votre téléphone - rien n'est téléchargé. Les dates détectées sont étiquetées « Détecté : veuillez vérifier » et nécessitent votre confirmation avant d'être enregistrées.

Oui ! Les utilisateurs gratuits peuvent partager les documents individuels. Les utilisateurs Pro obtiennent des outils batch puissants : sélectionnez des documents spécifiques (ou les profils de tous) et générez un PDF combiné unique optimisé pour l'impression. Vous pouvez même définir des noms de fichier personnalisés pour vos exports pour maintenir vos dossiers numériques organisés.

L'application stocke tout sur votre appareil. Si vous avez iCloud (iOS) ou Google Backup (Android) activé, vos documents sont déjà protégés via votre sauvegarde d'appareil. Les utilisateurs Pro peuvent exporter une sauvegarde chiffrée protégée par mot de passe pour la sauvegarde, et tous les utilisateurs peuvent restaurer à partir d'une sauvegarde à tout moment via Paramètres → Import du Coffre. Cela remplace toutes les données actuelles par le contenu de la sauvegarde. Nous n'avons intentionnellement pas synchronisé avec nos serveurs pour protéger votre vie privée.

L'application utilise les profils pour organiser les documents par membre de la famille, mais toutes les données restent sur votre appareil. Pour activer le verrou d'application, accédez à Paramètres → Verrou d'application dans l'application :

  • Verrou PIN (Gratuit) : Définissez un code PIN à 4 chiffres. L'application nécessitera ce code PIN chaque fois que vous l'ouvrez.
  • Verrou biométrique : Activez Face ID (iPhone avec Face ID), Touch ID (iPhone avec empreinte digitale) ou déverrouillage par empreinte digitale (Android). Gratuit pour tous les utilisateurs, car la sécurité ne devrait pas être payante.

Meilleure pratique : Activez le verrou d'application + définissez votre appareil pour verrouiller automatiquement après 30 secondes. Cela crée plusieurs couches de protection : verrou d'appareil, puis verrou d'application, puis fichiers chiffrés.

Important : PIN oublié : Si vous oubliez votre code PIN, le seul moyen de récupérer l'accès est de supprimer et réinstaller l'application, qui supprime définitivement toutes vos données. Pour vous protéger :

  • Exportez une sauvegarde chiffrée avant d'activer le verrou d'application (Paramètres → Export du Coffre)
  • Stockez votre code PIN quelque part de sûr (par exemple, le gestionnaire de mots de passe de votre appareil)
  • Activez le déverrouillage biométrique (gratuit pour tous les utilisateurs) afin que vous puissiez utiliser Face ID, Touch ID ou l'empreinte digitale au lieu de taper le code PIN
  • Si vous avez des sauvegardes d'appareil (iCloud/Google) activées, la restauration à partir d'une sauvegarde peut récupérer vos données après la réinstallation

Oui, l'application crée des sauvegardes locales automatiques tous les 5 minutes (quand l'application est ouverte et que des modifications sont apportées). Ces sauvegardes sont stockées sur votre appareil et sont incluses dans votre sauvegarde d'appareil iCloud (iOS) ou Google (Android) si vous avez ces services activés.

Comment ça marche :

  • L'application conserve 10 sauvegardes roulantes sur votre appareil. Lorsqu'une 11ème sauvegarde est créée, la plus ancienne est automatiquement supprimée.
  • Les sauvegardes sont chiffrées en utilisant la même protection que vos documents.
  • Si l'application plante ou vous supprimez accidentellement un document, vous pouvez restaurer à partir de la sauvegarde la plus récente via Paramètres → Import du Coffre.

Sauvegardes manuelles (Pro) : Les utilisateurs Pro peuvent également créer des sauvegardes ZIP chiffrées manuelles et les enregistrer dans Fichiers, iCloud Drive ou les partager via AirDrop/email pour le stockage hors appareil. Plateforme et Compatibilité

La version Android arrive au début 2026. Nous sommes actuellement en test fermé pour assurer que la même expérience de stockage sur appareil axée sur la confidentialité fonctionne parfaitement sur les appareils Android.

La version Android aura une parité des fonctionnalités avec iOS, y compris le stockage sur appareil chiffré, l'analyse OCR, les rappels d'expiration et toutes les fonctionnalités Pro (profils illimités, documents d'export en batch et programmation personnalisée des rappels).

Oui, en utilisant l'export de coffre chiffré (fonctionnalité Pro). Exportez une sauvegarde chiffrée de votre appareil actuel (Paramètres → Export du Coffre), transférez-la à votre nouvel appareil (via email, stockage cloud ou transfert direct), puis utilisez Paramètres → Import du Coffre pour restaurer vos documents.

Cela fonctionne entre les plateformes car le format de chiffrement est universel. Vous devrez utiliser le même mot de passe que celui utilisé lors de l'export du coffre. Votre achat Pro devra également être restauré sur le nouvel appareil (voir « Puis-je restaurer mon achat sur un nouvel appareil ? » ci-dessous).

L'application elle-même est petite (~15 Mo téléchargement). L'utilisation du stockage dépend entièrement du nombre de documents que vous stockez et de leur qualité photo. Une photo de passeport typique (haute qualité) fait 2-4 Mo. Avec 20 documents, attendez-vous à environ 40-80 Mo de stockage.

L'application inclut 10 sauvegardes automatiques, qui sont des copies compressées de vos documents, ajoutant un espace minimal (~10-20% de plus). Il n'y a pas de limite stricte au nombre de documents (les utilisateurs Pro obtiennent un nombre illimité), mais les limites pratiques dépendent du stockage disponible sur votre appareil.

Caméra : Pour capturer les photos de vos documents directement dans l'application. Photothèque : Pour importer les photos de documents existantes que vous avez déjà prises.

Nous ne téléchargeons jamais vos photos nulle part. Tout le traitement (y compris l'analyse OCR) se fait sur votre appareil. Vous pouvez refuser ces autorisations, mais vous ne pourrez pas ajouter de documents (la fonction principale de l'application). Si vous avez accidentellement refusé les autorisations, vous pouvez les réactiver dans les paramètres de votre appareil → Confidentialité → Caméra / Photos → Travel Document Vault.

Dépannage

Vérifiez que les notifications sont activées pour Travel Document Vault dans votre appareil Paramètres → Notifications. Assurez-vous également que vous avez ajouté une date d'expiration à votre document. Les rappels ne sont programmés que lorsqu'il y a une date d'expiration.

L'OCR fonctionne mieux avec un bon éclairage et un document plat. Essayez d'ajuster l'angle ou l'éclairage. Si la détection échoue, vous pouvez toujours entrer la date d'expiration manuellement. L'OCR est auxiliaire. Il est conçu pour aider, pas remplacer la saisie attentive des données.

La qualité du document dépend entièrement de votre appareil photo et des conditions d'éclairage. Nous ne modifions pas, n'améliorons pas ou n'améliorons pas les images. Ce que vous capturez est ce que vous obtenez. Pour de meilleurs résultats : utilisez un bon éclairage (la lumière naturelle fonctionne bien), tenez votre téléphone fermement, assurez-vous que le document est plat et entièrement visible dans le cadre et nettoyez votre lentille d'appareil photo. La même chose s'applique aux PDF exportés. La qualité d'impression reflète votre qualité de capture d'origine.
