Qu'est-ce que mon code de récupération ?

Votre code de récupération est une phrase de passe de 24 caractères qui déverrouille vos clés de chiffrement cloud. Si vous perdez toutes les copies du code et l’accès à tous les appareils capables de déverrouiller encore le coffre, nous ne pouvons pas récupérer ces sauvegardes. Nous ne la conservons pas et ne pouvons pas la réinitialiser, conservez-la donc dans un endroit sûr.

Fonctionnement

Ce qu'il est

Votre code de récupération est une phrase de passe de 24 caractères générée quand vous définissez votre PIN. Il ressemble à ceci :

XXXX-XXXX-XXXX-XXXX-XXXX-XXXX

Votre code de récupération déverrouille les clés de chiffrement nécessaires pour restaurer votre sauvegarde cloud avec Pro. L’application le génère lorsque vous définissez votre PIN et l’affiche une seule fois. Enregistrez une copie en lieu sûr.

Pourquoi vous en avez besoin

Avec la sauvegarde cloud Pro, l’application chiffre le contenu de vos documents sur votre appareil avec AES-256-GCM avant l’envoi. Votre code de récupération déverrouille les clés de chiffrement cloud. Vous en avez besoin pour restaurer une sauvegarde. Nous n’en détenons pas de copie.

Nous ne pouvons pas déchiffrer ni réinitialiser votre sauvegarde cloud pour vous. Si vous perdez toutes les copies de votre code de récupération et l’accès à tous les appareils capables de déverrouiller encore le coffre, nous ne pouvons pas récupérer cette sauvegarde.

Si vous le perdez

Si vous oubliez votre code de récupération, les possibilités dépendent de l’accès que vous avez encore à un appareil capable de déverrouiller le coffre et à son PIN :

  • Générer un nouveau code sur votre téléphone : Gardez la sauvegarde cloud activée et connectez-vous à Internet. Ouvrez Réglages, Sécurité, Code de récupération, confirmez et saisissez votre PIN. Enregistrez le nouveau code en lieu sûr, puis appuyez sur la confirmation d’enregistrement du code pour l’activer. Suivez les éventuelles invites pour vous reconnecter ou synchroniser.
  • Téléphone également perdu : Si vous n’avez ni copie du code de récupération ni autre appareil capable de déverrouiller encore le coffre, nous ne pouvons pas ouvrir la sauvegarde existante. Activez la sauvegarde cloud sur votre nouveau téléphone et choisissez Recommencer.

Où le stocker

Votre code de récupération est aussi sensible que votre mot de passe maître. Conservez-le d'une de ces façons :

  • Gestionnaire de mots de passe : Utilisez un gestionnaire de mots de passe de confiance.
  • Sauvegarde physique : Écrivez-le sur papier et conservez-le dans un coffre-fort, un coffre-fort bancaire ou un endroit sécurisé chez vous.
  • Document hors ligne : Enregistrez-le sur un disque externe chiffré ou une clé USB (jamais synchronisé dans le cloud).
  • À éviter : Email, application Notes, services cloud non chiffrés ou captures d'écran.

Régénération de votre code

Si vous pensez que votre code de récupération est compromis, gardez la sauvegarde cloud activée et connectez-vous à Internet. Ouvrez Réglages, Sécurité, Code de récupération, confirmez et saisissez votre PIN. Enregistrez le nouveau code affiché par l’application, puis appuyez sur la confirmation d’enregistrement du code pour l’activer. Suivez les éventuelles invites pour vous reconnecter ou synchroniser.

Avertissement : Votre code de récupération est votre seule responsabilité. Travel Document Vault ne peut pas le récupérer ni le réinitialiser pour vous s’il est perdu. Conservez-le de façon sécurisée. Ne vous fiez pas à cette application comme seul système de sauvegarde pour les documents critiques.

Prêt à protéger votre coffre-fort ?

Téléchargez Travel Document Vault gratuitement. Pro ajoute la sauvegarde chiffrée sur votre propre iCloud ou Google Drive. Enregistrez votre code de récupération avant de l’activer.
