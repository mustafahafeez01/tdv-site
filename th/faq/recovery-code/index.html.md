# รหัสการกู้คืนของฉันคืออะไร? | Travel Document Vault

> รหัสการกู้คืนของคุณคือกุญแจหลักสำหรับสำรองข้อมูลคลาวด์ที่เข้ารหัสของคุณ เรียนรู้ว่ามันคืออะไร ทำไมคุณต้องมี จะเกิดอะไรขึ้นหากทำหาย และวิธีเก็บรักษาอย่างปลอดภัย

Source: https://traveldocumentvault.com/th/faq/recovery-code/

---

รหัสการกู้คืนของคุณคือวลีรหัสผ่าน 24 ตัวอักษรที่เข้ารหัสสำรองข้อมูลคลาวด์ของคุณ หากคุณทำหาย สำรองข้อมูลเหล่านั้นจะไม่สามารถกู้คืนได้ เราไม่ได้เก็บหรือรีเซ็ตให้ ดังนั้นควรเก็บไว้ในที่ปลอดภัย

## วิธีการทำงาน

### มันคืออะไร

รหัสการกู้คืนของคุณคือวลีรหัสผ่าน 24 ตัวอักษรที่สร้างขึ้นเมื่อคุณเปิดใช้งานสำรองข้อมูลคลาวด์ มีรูปแบบคล้ายๆ กับ:

XXXX-XXXX-XXXX-XXXX-XXXX-XXXX

รหัสนี้ได้มาจากการคำนวณตามการตั้งค่าสำรองข้อมูลของคุณ และเป็นกุญแจเดียวที่สามารถถอดรหัสคลังที่เข้ารหัสของคุณบนคลาวด์ได้ เราสร้างมันเพียงครั้งเดียวและแสดงให้คุณเห็นเพียงครั้งเดียว หลังจากนั้น หน้าที่ในการเก็บรักษาให้ปลอดภัยเป็นของคุณ

### ทำไมคุณต้องมี

เมื่อคุณเปิดใช้งานสำรองข้อมูลคลาวด์ คลังทั้งหมดของคุณจะถูกเข้ารหัสบนอุปกรณ์ของคุณด้วย AES-256-GCM ก่อนที่จะออกจากโทรศัพท์ กุญแจเข้ารหัสได้มาจากรหัสการกู้คืนของคุณ หากไม่มีรหัสการกู้คืน สำรองข้อมูลจะไม่สามารถเข้าถึงได้ในทางเข้ารหัส แม้แต่กับเราเอง

นี่คือการรับประกันความเป็นส่วนตัว เราไม่สามารถอ่านสำรองข้อมูลของคุณ ถอดรหัสตามคำขอ หรือรีเซ็ตให้คุณได้จริงๆ หากรหัสการกู้คืนของคุณสูญหาย สำรองข้อมูลนั้นจะหายไปตลอดกาล ฟังดูรุนแรง แต่นี่คือสิ่งที่คุณต้องการจริงๆ ความเป็นส่วนตัวของคุณไม่ใช่แค่คำสัญญาที่เราให้ไว้ แต่เป็นข้อเท็จจริงทางเทคนิคที่เราไม่สามารถละเมิดได้

### หากคุณทำหาย

หากคุณลืมรหัสการกู้คืน สำรองข้อมูลคลาวด์ที่มีอยู่ของคุณจะไม่สามารถกู้คืนได้ คุณมีสองทางเลือก:

- **กู้คืนจากโทรศัพท์ของคุณ:** หากรหัสยังถูกเก็บไว้ในแอป (ตรวจสอบที่การตั้งค่า - สำรองข้อมูลคลาวด์) ให้คัดลอกไปเก็บไว้ในที่ปลอดภัยและบันทึกไว้
- **สร้างรหัสใหม่:** ปิดใช้งานสำรองข้อมูลคลาวด์แล้วเปิดใช้งานอีกครั้ง วิธีนี้จะสร้างรหัสการกู้คืนใหม่และทิ้งสำรองข้อมูลเดิม คุณจะเริ่มต้นใหม่

### จะเก็บไว้ที่ไหน

รหัสการกู้คืนของคุณมีความสำคัญเทียบเท่ารหัสผ่านหลักของคุณ เก็บรักษาด้วยวิธีใดวิธีหนึ่งต่อไปนี้:

- **ตัวจัดการรหัสผ่าน:** Bitwarden, 1Password, Apple Keychain หรือที่คล้ายกัน นี่คือตัวเลือกที่สะดวกที่สุด
- **สำรองแบบกายภาพ:** เขียนลงกระดาษและเก็บไว้ในตู้เซฟ ตู้นิรภัยธนาคาร หรือที่ปลอดภัยที่บ้าน
- **เอกสารออฟไลน์:** บันทึกลงในไดรฟ์ภายนอกหรือ USB ที่เข้ารหัส (ไม่ซิงค์กับคลาวด์เด็ดขาด)
- **หลีกเลี่ยง:** อีเมล แอปโน้ต บริการคลาวด์ที่ไม่เข้ารหัส หรือการแคปหน้าจอ

### การสร้างรหัสใหม่

หากคุณคิดว่ารหัสการกู้คืนของคุณถูกบุกรุก ให้ปิดสำรองข้อมูลคลาวด์แล้วเปิดกลับมาอีกครั้ง แอปจะสร้างรหัสการกู้คืนใหม่ สำรองข้อมูลที่เข้ารหัสเดิมของคุณจะถูกทิ้งไป นี่เป็นการออกแบบโดยตั้งใจ การหมุนเวียนรหัสการกู้คืนถูกออกแบบมาให้เกิดขึ้นได้ยากและสูญเสียข้อมูล เพื่อให้คุณไม่ทำเรื่องนี้โดยไม่คิดให้ดี

**ข้อจำกัดความรับผิด:** รหัสการกู้คืนของคุณเป็นความรับผิดชอบของคุณแต่เพียงผู้เดียว Travel Document Vault ไม่สามารถกู้คืน รีเซ็ต หรือสร้างรหัสใหม่ให้คุณได้หากทำหาย เก็บรักษาไว้อย่างปลอดภัย อย่าพึ่งพาแอปนี้เป็นระบบสำรองข้อมูลเพียงระบบเดียวสำหรับเอกสารสำคัญ
