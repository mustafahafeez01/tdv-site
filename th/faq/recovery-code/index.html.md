# รหัสการกู้คืนของฉันคืออะไร? | Travel Document Vault

> รหัสกู้คืนปลดล็อกข้อมูลสำรองบนคลาวด์ที่เข้ารหัส เรียนรู้ว่ามันคืออะไร ทำไมจึงสำคัญ และวิธีเก็บรักษาให้ปลอดภัย

Source: https://traveldocumentvault.com/th/faq/recovery-code/

---

รหัสการกู้คืนของคุณคือวลีรหัสผ่าน 24 ตัวอักษรที่ปลดล็อกกุญแจเข้ารหัสบนคลาวด์ หากคุณสูญเสียสำเนารหัสทั้งหมดและไม่สามารถเข้าถึงอุปกรณ์ทุกเครื่องที่ยังปลดล็อกคลังได้ เราจะกู้คืนข้อมูลสำรองเหล่านั้นให้ไม่ได้ เราไม่ได้เก็บหรือรีเซ็ตให้ ดังนั้นควรเก็บไว้ในที่ปลอดภัย

## วิธีการทำงาน

### มันคืออะไร

รหัสการกู้คืนของคุณคือวลีรหัสผ่าน 24 ตัวอักษรที่สร้างขึ้นเมื่อคุณตั้ง PIN มีรูปแบบคล้ายๆ กับ:

XXXX-XXXX-XXXX-XXXX-XXXX-XXXX

รหัสการกู้คืนปลดล็อกกุญแจเข้ารหัสที่ต้องใช้เพื่อกู้คืนข้อมูลสำรองบนคลาวด์ด้วย Pro แอปสร้างรหัสเมื่อคุณตั้ง PIN และแสดงให้เห็นครั้งเดียว เก็บสำเนาไว้ในที่ปลอดภัย

### ทำไมคุณต้องมี

เมื่อใช้สำรองข้อมูลคลาวด์ของ Pro แอปเข้ารหัสเนื้อหาเอกสารบนอุปกรณ์ด้วย AES-256-GCM ก่อนอัปโหลด รหัสการกู้คืนปลดล็อกกุญแจเข้ารหัสบนคลาวด์ คุณต้องใช้รหัสนี้เพื่อกู้คืนข้อมูลสำรอง เราไม่ได้เก็บสำเนาไว้

เราไม่สามารถถอดรหัสหรือรีเซ็ตข้อมูลสำรองบนคลาวด์ให้คุณได้ หากคุณสูญเสียสำเนารหัสการกู้คืนทั้งหมดและไม่สามารถเข้าถึงอุปกรณ์ทุกเครื่องที่ยังปลดล็อกคลังได้ เราจะกู้คืนข้อมูลสำรองนั้นให้ไม่ได้

### หากคุณทำหาย

หากคุณลืมรหัสการกู้คืน สิ่งที่ทำได้ขึ้นอยู่กับว่าคุณยังมีอุปกรณ์ที่ปลดล็อกคลังได้และมี PIN หรือไม่:

- **สร้างรหัสใหม่บนโทรศัพท์ของคุณ:** เปิดสำรองข้อมูลคลาวด์ไว้และเชื่อมต่ออินเทอร์เน็ต เปิดการตั้งค่า ความปลอดภัย รหัสการกู้คืน ยืนยันและป้อน PIN บันทึกรหัสใหม่ที่แอปแสดง แล้วแตะจดแล้วเรียบร้อยเพื่อเปิดใช้รหัสใหม่ ทำตามคำแนะนำหากต้องเชื่อมต่อใหม่หรือซิงค์
- **โทรศัพท์ก็หายด้วย:** หากคุณไม่มีสำเนารหัสการกู้คืนและไม่มีอุปกรณ์อื่นที่ยังปลดล็อกคลังได้ เราจะเปิดข้อมูลสำรองเดิมให้ไม่ได้ เปิดสำรองข้อมูลคลาวด์บนโทรศัพท์ใหม่แล้วเลือกเริ่มต้นใหม่

### จะเก็บไว้ที่ไหน

รหัสการกู้คืนของคุณมีความสำคัญเทียบเท่ารหัสผ่านหลักของคุณ เก็บรักษาด้วยวิธีใดวิธีหนึ่งต่อไปนี้:

- **ตัวจัดการรหัสผ่าน:** ใช้ตัวจัดการรหัสผ่านที่คุณเชื่อถือ
- **สำรองแบบกายภาพ:** เขียนลงกระดาษและเก็บไว้ในตู้เซฟ ตู้นิรภัยธนาคาร หรือที่ปลอดภัยที่บ้าน
- **เอกสารออฟไลน์:** บันทึกลงในไดรฟ์ภายนอกหรือ USB ที่เข้ารหัส (ไม่ซิงค์กับคลาวด์เด็ดขาด)
- **หลีกเลี่ยง:** อีเมล แอปโน้ต บริการคลาวด์ที่ไม่เข้ารหัส หรือการแคปหน้าจอ

### การสร้างรหัสใหม่

หากคุณคิดว่ารหัสการกู้คืนถูกบุกรุก ให้เปิดสำรองข้อมูลคลาวด์ไว้และเชื่อมต่ออินเทอร์เน็ต เปิดการตั้งค่า ความปลอดภัย รหัสการกู้คืน ยืนยันและป้อน PIN บันทึกรหัสใหม่ที่แอปแสดง แล้วแตะจดแล้วเรียบร้อยเพื่อเปิดใช้รหัสใหม่ ทำตามคำแนะนำหากต้องเชื่อมต่อใหม่หรือซิงค์

**ข้อจำกัดความรับผิด:** รหัสการกู้คืนของคุณเป็นความรับผิดชอบของคุณแต่เพียงผู้เดียว Travel Document Vault ไม่สามารถกู้คืนหรือรีเซ็ตให้คุณได้หากทำหาย เก็บรักษาไว้อย่างปลอดภัย อย่าพึ่งพาแอปนี้เป็นระบบสำรองข้อมูลเพียงระบบเดียวสำหรับเอกสารสำคัญ
