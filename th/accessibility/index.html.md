# ฟีเจอร์การเข้าถึง | Travel Document Vault

> Travel Document Vault สร้างสำหรับทุกคน เรียนรู้เกี่ยวกับฟีเจอร์ VoiceOver Dynamic Type โหมดมืด และ Reduce Motion ของเรา ในแอปที่ทำงานแบบออฟไลน์และเก็บเอกสารของคุณไว้ในอุปกรณ์ของคุณเอง

## ฟีเจอร์การเข้าถึง

### การสนับสนุน VoiceOver

ทุกหน้าจอใน Travel Document Vault ได้รับการบรรยายโดย VoiceOver อย่างสมบูรณ์ นำทาง สแกนเอกสาร ตั้งการแจ้งเตือน และจัดการตัวอักษรของคุณโดยใช้ท่าทาง แป้นพิมพ์ เบรลล์ และเอาต์พุตเสียง

- ป้ายกำกับเชิงพรรณนาสำหรับองค์ประกอบโต้ตอบทั้งหมด
- ลำดับชั้นส่วนหัวที่เหมาะสมสำหรับการนำทางที่ง่าย
- คำอธิบายปุ่มและการควบคุมที่มีความหมาย
- ประกาศสถานะสำหรับการเปลี่ยนแปลงที่สำคัญ

### ข้อความที่ใหญ่ขึ้น (Dynamic Type)

ข้อความทั้งหมดในแอปปรับขนาดตามค่ากำหนดขนาดข้อความของระบบของคุณ เพิ่มขนาดข้อความให้เป็น 200% หรือมากกว่า และเลย์เอาต์ของแอปจะปรับตัวโดยอัตโนมัติ

ปรับขนาดข้อความใน **การตั้งค่า → การเข้าถึง → การแสดงผลและขนาดข้อความ → ข้อความที่ใหญ่ขึ้น** บนอุปกรณ์ของคุณ

### อินเทอร์เฟซมืด

Travel Document Vault สนับสนุนทั้งโหมด Light และ Dark แอปจะจับคู่ลักษณะที่ปรากฏของระบบของคุณโดยอัตโนมัติ หรือคุณสามารถตั้งค่าธีมที่ต้องการของคุณในการตั้งค่า

ตัวเลือก: **ระบบ (อัตโนมัติ)**, **สว่าง**, หรือ **มืด**

### ความแตกต่างเพียงพอ

ข้อความและองค์ประกอบโต้ตอบทั้งหมดตรงตามมาตรฐานความแตกต่าง WCAG AAA (4.5:1 สำหรับข้อความปกติ 3:1 สำหรับข้อความขนาดใหญ่) สีความแตกต่างสูงช่วยให้อ่านได้ง่ายในสภาพแสงทั้งหมด

ระบบสีของเรามีอัตราส่วนความแตกต่าง 15:1+ สำหรับข้อความหลักในทั้งธีมสว่างและมืด

### แยกแยะโดยไม่ใช้สีเพียงอย่างเดียว

ข้อมูลที่สำคัญจะไม่ถูกส่งผ่านสีเพียงอย่างเดียว ตัวบ่งชี้สถานะใช้ไอคอน รูปร่าง และป้ายกำกับข้อความนอกเหนือจากสี

- เครื่องหมายถูกสีเขียวสำหรับเอกสารที่ถูกต้อง (ไม่ใช่แค่สีเขียว)
- ไอคอนเตือนสำหรับเอกสารที่กำลังจะหมดอายุ (ไม่ใช่แค่สีเหลืองหรือสีส้ม)
- ตัวบ่งชี้ข้อผิดพลาดด้วยไอคอน X (ไม่ใช่แค่สีแดง)

### การเคลื่อนไหวที่ลดลง

แอนิเมชั่นและเอฟเฟกต์การเคลื่อนไหวทั้งหมดให้ความเคารพต่อการตั้งค่า Reduce Motion ของคุณ เมื่อเปิดใช้งาน แอนิเมชั่นจะถูกย่อขนาดหรือลบออกเพื่อป้องกันการเวียนศีรษะและความรู้สึกไม่สบาย

เปิดใช้งานใน **การตั้งค่า → การเข้าถึง → การเคลื่อนไหว → ลดการเคลื่อนไหว** บนอุปกรณ์ของคุณ

## พิจารณาการเข้าถึงเพิ่มเติม

เป้าหมายการแตะ 44pt

องค์ประกอบโต้ตอบทั้งหมดตรงตามขนาดเป้าหมายการแตะขั้นต่ำ 44pt ของ Apple เพื่อการแตะที่ง่าย

การนำทางด้วยแป้นพิมพ์

นำทางแอปทั้งหมดโดยใช้แป้นพิมพ์ที่เชื่อมต่อกับอุปกรณ์ของคุณ

ฟอนต์ที่อ่านได้

ฟอนต์ระบบที่ปรับให้เหมาะสำหรับความสามารถในการอ่านในทุกขนาด

ข้อความข้อผิดพลาดที่ชัดเจน

สถานะข้อผิดพลาดจะประกาศให้ VoiceOver ได้ยินและแสดงด้วยข้อความที่ชัดเจนและสามารถดำเนินการได้

## เรากำลังปรับปรุงอยู่เสมอ

การเข้าถึงคือการมุ่งมั่นอย่างต่อเนื่อง หากคุณพบปัญหาใด ๆ ขณะใช้ Travel Document Vault หรือมีข้อเสนอแนะเพื่อปรับปรุง โปรดแจ้งให้เราทราบ
