## Функції доступності

### Підтримка VoiceOver

Кожен екран Travel Document Vault повністю озвучується VoiceOver. Навігація, сканування документів, налаштування нагадувань і керування сховищем доступні через жести, клавіатуру, брайль та голосовий вивід.

- Описові мітки для всіх інтерактивних елементів
- Правильна ієрархія заголовків для зручної навігації
- Змістовні описи кнопок і елементів керування
- Оголошення стану для важливих змін

### Збільшений текст (Dynamic Type)

Весь текст застосунку адаптується до розміру шрифту, встановленого в системі. Збільшуйте текст до 200% і більше, макет застосунку підлаштовується автоматично.

Налаштуйте розмір тексту в **Налаштування → Доступність → Екран і розмір тексту → Більший текст** на Вашому пристрої.

### Темний інтерфейс

Travel Document Vault підтримує як світлий, так і темний режим. Застосунок автоматично адаптується до системного оформлення або Ви можете встановити бажану тему в Налаштуваннях.

Варіанти: **Система (автоматично)**, **Світла** або **Темна**.

### Достатній контраст

Весь текст та інтерактивні елементи відповідають стандартам контрасту WCAG AAA (4,5:1 для звичайного тексту, 3:1 для великого). Кольори з високим контрастом забезпечують читабельність за будь-яких умов освітлення.

Наша колірна схема забезпечує коефіцієнт контрасту понад 15:1 для основного тексту у світлій і темній темах.

### Розрізнення без покладання лише на колір

Важлива інформація ніколи не передається лише через колір. Індикатори стану використовують іконки, форми та текстові мітки на додаток до кольору.

- Зелені галочки для дійсних документів (не лише зелений колір)
- Іконки попередження для документів, що скоро закінчуються (не лише жовтий/помаранчевий колір)
- Індикатори помилок з іконкою X (не лише червоний колір)

### Зменшення руху

Всі анімації та рухові ефекти поважають Ваші налаштування зменшення руху. Коли ця функція увімкнена, анімації мінімізуються або вимикаються, щоб запобігти нудоті від руху та дискомфорту.

Увімкніть у **Налаштування → Доступність → Рух → Зменшити рух** на Вашому пристрої.

## Додаткові міркування щодо доступності

Сенсорні зони 44 pt

Всі інтерактивні елементи відповідають мінімальному розміру сенсорної зони Apple 44 pt для зручного натискання.

Навігація з клавіатури

Навігація по всьому застосунку за допомогою клавіатури, підключеної до Вашого пристрою.

Читабельні шрифти

Системні шрифти, оптимізовані для читабельності у всіх розмірах.

Зрозумілі повідомлення про помилки

Стани помилок оголошуються VoiceOver і відображаються чітким, орієнтованим на дію текстом.
