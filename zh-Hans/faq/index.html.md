## 信任和透明度

开发者可以看到我的文件吗？

不会。本地保险库无需 Travel Document Vault 账户或服务器。文档默认保存在您的设备上。如果开启可选的 Pro 云备份，保险库会先在设备上完成端到端加密，再上传到您自己的 iCloud（iOS）或 Google Drive（Android），并由只有您持有的恢复码保护。我们不接收云备份，也无法读取其中加密的文档内容。Apple 和 Google 同样无法读取。

Sentry 崩溃报告收集什么，我可以关闭它吗？

Sentry 是一个崩溃报告工具，可帮助我们查找和修复错误。默认情况下**禁用**，关闭时不会发送任何内容。如果在“设置”中启用，它会发送经过清理的技术崩溃诊断。会话回放需要单独选择开启。报告会经过清理以减少个人数据，不会有意附加文档文件。

Pro 升级包括什么？

Pro 是一次性购买，解锁不限数量的档案、不限数量的证件、合并导出 PDF、加密云备份到 iCloud 或 Google Drive，以及自定义提醒时间。你只付一次费用，没有订阅，没有周期扣款，也没有悄悄开始收费的试用。

购买时包括将来的更新吗？

是的。您的购买涵盖当前主要版本（v1.x）中的每次更新，包括错误修复、安全补丁和新功能。用户反馈驱动的改进，如可用性更改和新文件类型，是这些正常更新的一部分。如果我们曾经发布具有大幅重建功能集的 v2.0，那可能是单独的购买，但我们会提前通知早期采用者并提供优惠定价。早期信任该应用的人是它变得更好的原因，我们不会认为这是理所当然的。

如果我丢失了我的手机或切换到新手机怎么办？

Pro 用户：在“设置”中的“云备份”开启加密云备份。保险库在上传到 iCloud（iOS）或 Google Drive（Android）前，会在设备上使用恢复码保护的密钥加密。请在同一平台上的受支持设备上使用同一云账户。在“设置”中打开“云备份”，选择备份并使用恢复码恢复。恢复会替换本地保险库。文档内容已加密；云服务商可以看到数量、时间戳和设备信息等备份元数据。我们看不到备份。所有用户：在“设置”中使用免费的 导出保险库（.tdvault），再导入到其他设备。系统备份（iCloud 或 Google）可以重新安装应用，但不能恢复文档，因为系统备份不会传输绑定设备的加密密钥。换手机前请先导出。

应用可以在没有互联网连接的情况下工作吗？

是的。核心应用无需服务器，也无需联网。扫描、查看、导出和提醒都可离线使用。商店购买与恢复购买、更新检查与下载，以及可选的 Pro 云备份到您自己的 iCloud 或 Google Drive，都需要网络连接。开启云备份时更改恢复码也需要联网。

该应用支持什么语言？

该应用可用于超过40种语言，包括对阿拉伯语、乌尔都语和波斯语的完全从右到左语言支持。您手机的语言会自动检测，您可以随时在设置中更改它。如果您的语言中有任何内容看起来不对，我们真的想知道。请写信至[support@traveldocumentvault.com](mailto:support@traveldocumentvault.com)，这将直接影响路线图。

如果你停止开发该应用怎么办？

文档保存在您的设备上，而不是我们的服务器上，因此不会因我们停止发布更新而消失。访问已保存的保险库不依赖 Travel Document Vault 服务器；未来操作系统的兼容性无法保证。您也可以导出加密的保险库副本，但须遵守导出大小限制，且附件文件须可读取。

谁开发了这个应用，为什么隐私是首要考量？

Travel Document Vault 由 Mustafa Hafeez 开发。他是一位资深软件开发者，多年来专注于构建尊重隐私的应用，也是一位因为自己家庭需要而做了这个应用的家长。隐私不是一句营销话术。本地保险库无需 Travel Document Vault 账户或服务器。在已解锁的手机上，请启用应用锁以限制访问。可选的云备份使用您自己的 iCloud 或 Google Drive，并以只有您持有的恢复码保护的密钥进行端到端加密。这是刻意的工程决定，而不是一项可以用开关改掉的政策。

## 隐私和数据

我的数据存储在哪里？

默认情况下，所有数据均以**独占方式存储在您的设备上**。我们没有存储文档的服务器，也没有 Travel Document Vault 用户账户。保存文档时，它留在手机的安全存储区域中。Pro 用户可以启用可选的云备份，将保险库的端到端加密副本保存到您自己的 iCloud 或 Google Drive。我们仍然无法读取。

我的数据是否备份到云？

该应用没有云数据库。我们看不到您的数据。如果您对整个手机使用**iCloud 备份**（iOS）或**Google 备份**（Android），该应用的数据包含在该包中。**您的数据在这些备份中保持加密。**此过程由您的操作系统管理，不是我们。

如果我丢失了我的手机怎么办？

系统级设备备份（iCloud Backup、Google Backup）可重新安装应用，但不会恢复文档，因为系统备份不会传输绑定设备的加密密钥。迁移到新手机请使用云备份（Pro）或免费的 导出保险库。

**保护您的数据：**从设置中导出您的保险库（.tdvault 文件，所有用户免费），保存在安全位置。Pro 用户还可以启用加密云备份。

如果有人偷我的手机怎么办？我的文件受保护吗？

是的。存储在保险库中的原始图像和 PDF 均经过**加密**。查看、扫描和分享可能生成临时的可读副本。没有解密密钥，就无法读取已加密存储的原始文件。

- **磁盘加密：**保存前，每个文档图像和 PDF 都被加密。
- **应用锁：**通过在应用设置中启用 PIN、Face ID 或 Touch ID 来添加第二层防御。

**重要：**最大安全性需要强设备密码。如果您的设备被解锁，拥有电话的人可能可以访问加密密钥。

你们收集任何分析或跟踪数据吗？

**否。**我们不使用任何分析 SDK、广告网络或跟踪服务。我们使用的唯一外部服务是**Sentry**进行崩溃报告（可在设置中禁用）。崩溃报告仅包含技术信息。永远不会是您的文件或个人数据。

删除应用时会发生什么？

卸载应用时，所有数据均**删除**。除非您已导出保险库或开启云备份，否则之后无法恢复，因为我们不在外部存储文档。**删除前：**通过“设置”导出文档或创建加密备份文件（.tdvault），保存到其他位置。

## 额外的安全性

我的文件图像是否加密？

**是的。**存储在保险库中的原始图像和 PDF 均经过加密。查看、扫描和分享可能生成临时的可读副本。没有解密密钥，就无法读取已加密存储的原始文件。

**为了获得最大安全性：**我们建议启用应用锁定并使用强设备密码。有关完整详细信息，请参阅我们的[隐私政策](https://traveldocumentvault.com/privacy-policy/)。

你们可以访问我的文件吗？

**默认情况下，**文档保存在您的设备上，无需上传到 Travel Document Vault 服务器。Pro 用户可以启用加密云备份，将副本保存到您自己的 iCloud（iOS）或 Google Drive 隐藏应用文件夹（Android）。我们无法访问文档内容；部分备份元数据仍可读取。

由于您的数据永远不会到达我们的服务器，我们无法访问、查看或恢复您的文件。这是为了保护您的隐私而进行的设计。

备份也加密吗？

**是的。**导出保险库（.tdvault 文件）采用强加密，并且**受密码保护**。导出时设置密码，恢复时需要该密码。

如果您从备份恢复，您的文件将自动在您的新设备上工作，而无需您执行任何特殊操作。

"向他人展示"是什么意思？

“向他人展示”是供边境官员、酒店前台或航空公司工作人员查看屏幕上文档的受保护显示模式。设置 PIN 锁后，点击图标打开全屏视图，默认启用**屏幕截图和录屏保护，**具体效果取决于设备支持和您的设置。关闭受保护视图后，使用 PIN 或已启用的生物识别解锁保险库。

此显示模式不会上传文档。请先设置 PIN 锁，关闭受保护视图时才会锁定保险库访问。如果没有 PIN 锁，查看器不会限制对保险库其他内容的访问。

什么是恢复代码，为什么我需要它？

设置应用锁时，应用会生成一个唯一的恢复代码，它是您忘记 PIN 时的安全网。将其保存在安全的地方——您的密码管理器、打印的记录或您信任的任何地方。

如果忘记 PIN，请在 PIN 页面输入恢复码。恢复码会解锁应用，**不会删除您的文档。**应用锁仍保持开启。

如果 PIN 和已启用的生物识别都无法解锁应用，且没有恢复码，您可能需要清除本地保险库，再恢复已保存的备份。请在提示时保存恢复码。在仍知道 PIN 的情况下，可在“设置”→“安全”生成新恢复码。

什么是自动删除？

自动清除旨在多次输入错误 PIN 后清除本手机的保险库。请勿将其视为有保证的保护措施。设置 PIN 后，**它默认开启。**如果希望在验证失败后保留数据，可在“设置”→“安全”关闭。完成本地清除后，本手机的保险库会被移除；恢复需要独立且可用的备份。

**重要提示：**在依赖自动清除之前，先创建保险库导出备份。这样即使误触发，也可以从备份恢复。请保留独立备份及所需的密码或恢复码。

## 功能

我可以存储哪些文件类型？

该应用支持**护照**、**国家身份证**（正反两面）、**签证/居留许可证**、**航班票据**、**代金券和入场券**（礼品卡、促销代码、活动票，附有有效期提醒，以便它们不会浪费）、**其他文件**（旅行保险、健康保险、接种记录、会员资格、处方，以及任何有有效期的东西）和**笔记**（仅用于期限和提醒的纯文本）。您可以使用相机捕获文件、从照片库导入或导入 PDF 文件。Pro 用户可以为航班票据、代金券和其他文件捕获多页文件。

有效期提醒如何工作？

提醒自动启动，时间取决于证件类型。护照在有效期前 8 个月开始提醒（续约通常需要 6-8 周），然后依次为 6 个月、3 个月、6 周、1 个月、2 周、1 周，以及有效期当日。签证、国家身份证和旅行保险从 3 个月前开始。即使错过截止日期，我们也会在有效期后**第二天**和**一周后**提醒您，以帮助您开始续约。航班票据采用更紧密的安排（提前 1 周、2 天、1 天、24 小时），且没有有效期后提醒，因为航班已经起飞。

什么是 OCR，它如何工作？

OCR（光学字符识别）自动检测文档中的到期日。将相机对准文档，应用会尝试读取到期日。所有处理均在手机上进行，不会上传。勾选“我确认此日期正确”以接受检测结果，或在保存前手动修改日期。

我可以导出我的文件吗？

是的。免费用户可以分享单份文档。Pro 提供合并 PDF 导出：选择特定文档（或所有人的档案），生成用于打印的**单个合并 PDF**。您可以设置自定义文件名，方便整理导出文件。

应用如何备份我的数据？

Pro：开启加密云备份，将副本保存到您自己的 iCloud（iOS）或 Google Drive（Android）。保险库在上传前于设备上加密，恢复码保护其密钥。我们看不到备份。文档内容已加密，云服务商可看到数量、时间戳和设备信息等备份元数据。应用打开且联网时会自动备份。恢复需要同一平台上的受支持设备、同一云账户和恢复码。**恢复会替换本地保险库。**

我可以与家庭成员共享文件吗？

该应用使用**资料**按家庭成员组织文件，但所有数据都保留在您的设备上。没有共享访问或设备之间的同步。如果您需要共享文件，可以使用系统分享表导出它并通过 AirDrop、电子邮件或消息发送。

应用可以离线工作吗？

**是的。**您可以离线添加文档、查看已保存副本和接收到期提醒。云备份、购买和更新需要网络连接。

我如何通过 PIN 或 Face ID/Touch ID 启用应用锁定？

要启用应用锁定，请在应用中转到**设置 → 安全**：

- **PIN 锁（免费）：**设置6位 PIN。应用锁在需要时要求验证；已启用的生物识别可代替 PIN 输入，短暂切换应用有五秒宽限期。
- **生物识别锁：**启用 Face ID（带 Face ID 的 iPhone）、Touch ID（带指纹的 iPhone）或指纹解锁（Android）。免费提供给所有用户，因为安全性不应该被付费。

**最佳实践：**启用应用锁定 + 将设备设置为 30 秒后自动锁定。这创建了多层保护：设备锁定、然后应用锁定、然后加密文件。

**重要：忘记 PIN：**如果您忘记 PIN，唯一的访问权限是删除并重新安装该应用，这会**永久删除所有数据**。为了保护自己：

- 在启用应用锁定**之前**导出加密备份（设置 → 导出保险库）
- 将 PIN 存储在安全地方（例如您的设备密码管理器）
- 启用**生物识别解锁**（对所有用户免费），以便您可以使用 Face ID、Touch ID 或指纹而不是输入 PIN
- 如果启用了设备备份（iCloud/Google），重新安装后从备份恢复可能会恢复您的数据

该应用是否创建自动备份？

**是的，应用每隔几分钟自动创建本地备份**（当应用打开且进行更改时）。备份保存在您的设备上。iCloud 或 Google 设备备份无法通过它们找回文档，因为系统备份不会传输绑定设备的加密密钥。

**工作原理：**

- 应用在您的设备上保留**几个滚动备份**。达到本地保留上限后，旧备份会轮换移除。
- 备份保存在设备上应用的私有存储区域中。****
- 有效的本地备份可通过**设置 → 从本地备份恢复**还原较早的保险库记录，但不能重建已永久删除的附件文件。普通删除请使用“最近删除”。

**Vault Export：**前往设置，随时导出加密的 .tdvault 文件。保存到"文件"、iCloud Drive，或通过 AirDrop/电子邮件分享，用于离设备存储。所有用户均可免费使用。

我可以自定义提醒时间吗？

**免费用户：**获得按证件类型智能选择的默认提醒。护照从提前 8 个月开始，签证和身份证从提前 3 个月开始，票证和预订从提前 1 周开始，每种都自动级联至有效期。

**Pro 用户：**可以更改任何证件的起始提醒时间。选择 8 个月、6 个月、3 个月、6 周、1 个月、2 周、1 周或有效期当日，其余日程自动从该点填充。航班票证有各自的选择：提前 1 周、2 天、1 天或 24 小时。

要自定义提醒，请点击任何文件 → 编辑 → 提醒部分（仅 Pro）。

我如何选择多个文件？

打开文档列表的更多菜单，点击**“选择证件”**进入选择模式。点击文档以选择或取消选择，然后使用底部的**删除、分享或 PDF**控件删除选中文档、分享原始文件，或导出合并 PDF（Pro）。您也可以**长按**文档卡片，打开针对该文档的快捷菜单。

我可以撤销批量删除吗？

**是的——您有两层保护。**删除文件（单个或批量）后，您会在屏幕底部看到一个短撤销窗口。点击**"撤销"**立即恢复它们。如果您错过了撤销窗口，已删除的文件将移至设置中的**最近删除**，在永久删除前保留 30 天。启用云备份的 Pro 用户将在最近删除中无限期保留项目，直到他们点击永久删除。

什么是长按上下文菜单？

长按（按住）列表中的任何文件卡以打开快速操作菜单。从那里你可以**导出 PDF**、**分享原始**文件或**删除**文件而无需先打开它。当菜单出现时，您会感到细微的触觉点击。这适用于所有用户（免费和 Pro）。

我可以存储医疗或处方文件吗？

是的。您可以保存健康保险卡、重复处方、接种记录及其他健康相关文档。选择**备注**或**其他**并保存到期日。提醒默认开启，时间取决于文档类型。文档加密保存在设备上。如果开启可选的 Pro 云备份，加密副本会保存到您自己的 iCloud 或 Google Drive，并由只有您持有的恢复码保护。

我可以延迟提醒吗？

是的。提醒触发时，可直接从通知中**延后提醒**。选择1小时、3小时、明天或下周。应用会自动重新安排。也可在应用内的“提醒”选项卡中延后。应用会按您选择的时间安排延后提醒。

我可以给文件编码颜色吗？

每个文件卡都自动编码为颜色。**绿色**表示有效，**琥珀色**表示有效期即将到来，**红色**表示过期或即将过期。您可以一目了然地看到整个保管库的状态，无需打开任何单个文件。

**Pro 用户**可以走得更远：从个人资料设置选项卡中按文件类型覆盖颜色。为护照、签证或任何您想要突出的类别分配不同的颜色。这叠加在状态颜色之上，因此您始终同时看到类别和紧迫性。

我可以将照片附加到我的笔记中吗？

是的。笔记和凭证支持多个图像附件。免费用户可以为每个笔记附加一个图像。**Pro 用户最多可以附加 10 个。**附加确认电子邮件的照片、QR 代码、预订参考或任何添加上下文的内容。每个图像都在您的设备上加密，就像您保管库的其余部分一样。

## 故障排除

我没有收到提醒通知

检查您的设备"设置 → 通知"中为 Travel Document Vault 启用了通知。还要确保为您的文件添加了有效期。仅当有有效期时才会安排提醒。

OCR 没有检测到我的有效期

OCR 在良好的光线和平坦的文件上效果最佳。尝试调整角度或照明。如果检测失败，您总是可以手动输入有效期。OCR 是辅助性的。它旨在帮助，而不是替代仔细的数据输入。

为什么我的文件图像模糊或质量低？

文档质量取决于原始图像、光线，以及应用的裁剪、缩放和压缩。已保存的照片可能经过裁剪、缩放和压缩；OCR 可能增强临时副本以识别文字。为获得较好效果，请使用充足光线、保持手机稳定、确保文档平整且完整入镜，并清洁镜头。导出 PDF 同样如此，打印质量反映原始拍摄质量。

应用崩溃了。我是否丢失了数据？

可能不会。当您添加或编辑文件时，您的数据会自动保存。崩溃不应该导致数据丢失。重新打开应用并检查您的文件。如果您看到问题，请通过 support@traveldocumentvault.com 与我们联系。

该行显示最近一次自动本地备份的保存时间和包含的文档数量。这是最新的本地快照。点击“从本地备份恢复”可还原已保存的记录。本地快照不包含附件文件的独立副本。

如何从本地备份恢复保险库？

前往“设置”，点击“从本地备份恢复”。应用会列出带时间戳的可用备份，选择所需备份并确认。如果要从已导出的 .tdvault 文件恢复，请改用“导入备份”并选择文件。两种方式均免费。恢复会用备份内容替换当前数据。

应用显示恢复界面或提示数据无法加载，该怎么办？

如果应用无法读取本地存储，会显示恢复页面并保留无法读取的数据。点击“恢复”，从某个自动本地备份恢复，或前往“设置”点击“导入备份”，导入之前导出的 .tdvault 文件。近期更新之前创建的备份也可恢复。原有数据会保留，不会删除。

为什么应用在更新前会创建备份？

重大数据格式升级前，应用会自动创建保险库快照。如果有有效且可读取的升级前快照，可尝试从“设置”恢复。此过程自动进行，对所有人免费。

在境内的天数还是在境外的天数，该选哪个？

先问自己一个问题：你是这个国家的访客，还是这里就是你的家？ 访客计算待在当地的天数，所以选择**在境内的天数**——这是用于 90 天之类访客上限的设置。 居民计算离开的天数，所以选择**在境外的天数**——这是用于允许一定时间在境外的居留许可的设置。 多数人只需要其中一个，如果拿不准，在境内的天数是更常见的选择。

通过 Pro，档案可帮助您在同一个保险库内整理每位家庭成员的文档、照片和提醒。档案没有独立访问锁。开启云备份后，档案会同步到连接同一云端保险库的设备。

已删除的项目进入垃圾箱 30 天。

## 云备份

开启云备份后删除证件会怎样？

删除会把它移到“最近删除”（回收站）。它会一直留在那里，开启云备份时不会自动清理。回收站里的证件仍然包含在你的云备份中。要彻底移除，请进入“最近删除”，对每一项点击“永久删除”。系统会提示这同时会把它从云备份中移除。

如果我删除了所有证件会怎样？

应用会阻止部分空保险库上传，以保护现有备份；已删除记录和其他保险库数据仍可能同步。恢复取决于是否保留了可用备份。您可以通过“设置”“云备份”“从备份恢复”还原。

如何在第二台设备上设置云备份？

在登录同一 iCloud 或 Google 账户的新设备上开启云备份时，应用会检测现有备份，并询问要恢复还是新建备份。选择备份，点击“恢复”并输入恢复码。两台设备随后共用同一份备份。如果选择新建备份，现有备份会保持不变。

可以同时在多台设备上使用云备份吗？

可以，在“设置”→“云备份”中开启“跨设备同步”。同一平台上的设备会在应用打开且联网时检查更改。部分更改会自动合并；部分冲突允许选择版本，但比较中不会显示备注文字。换到新设备时，请在新设备上恢复备份。

如果我在离线状态下开启云备份会怎样？

开启云备份需要联网。设置过程中应用会检查你的账户里是否已有备份，这需要网络连接。开启之后，应用可以完全离线使用，等你重新联网时再同步。

如果我不小心删掉了东西，备份还安全吗？

有多层保护。已删除文档会无限期保留在“最近删除”中，开启云备份时不会自动清理。永久删除需要单独确认，并提示对云端的影响。较早的备份版本可能保留文档，直到历史保留期限到期或备份清理移除它。空保险库上传保护和保留的备份版本可能有助于误删后的恢复；也请保留独立导出文件。

我还需要自己另外留备份吗？

需要。云备份是一层保护，但没有哪个系统是完美的。云账户可能丢失，恢复码可能被遗忘，同步或存储也可能出现意外问题。我们强烈建议为重要证件保留一份独立的副本，例如放在安全地方的纸质件，或保存在其他存储介质上的加密保险库导出文件。请把云备份当作便利，而不是唯一的防线。确认你的证件仍然可以恢复，这是你自己的责任。

如果我弄丢了恢复码会怎样？

恢复码用于解锁云备份的加密密钥；已配置设备会保留密钥以自动备份。我们采用零知识设计，无法为您重置、取回或恢复恢复码，Apple 和 Google 也无法。如果您丢失恢复码，也无法再访问任何保留密钥的已配置设备，加密云备份就无法恢复。依赖云备份前，请将恢复码保存在安全的地方，如密码管理器、安全位置的纸质副本，或两者都有。将其作为唯一副本前，先确认能读取。
