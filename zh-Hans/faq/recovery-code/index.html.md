恢复码是用于解锁云端加密密钥的24字符密码短语。如果您丢失所有副本，也无法再访问任何能够解锁保险库的设备，我们就无法恢复备份。我们不持有或重置恢复码，请妥善保管。

## 它的工作原理

### 它是什么

恢复码是在设置 PIN 时生成的24字符密码短语。它看起来像：

XXXX-XXXX-XXXX-XXXX-XXXX-XXXX

恢复码用于解锁通过 Pro 恢复云备份所需的加密密钥。应用在您设置 PIN 时生成它，并只显示一次。请将副本保存在安全的地方。

### 为什么需要它

通过 Pro 云备份，应用会在上传前使用 AES-256-GCM 在设备上加密文档内容。恢复码用于解锁云端加密密钥。恢复备份时需要它。我们不持有副本。

我们无法为您解密或重置云备份。如果您丢失所有恢复码副本，也无法再访问任何能够解锁保险库的设备，我们就无法恢复该备份。

### 如果丢失它

如果您忘记恢复码，能采取什么措施取决于您是否仍有能够解锁保险库的设备并知道其 PIN：

- **在手机上生成新恢复码：**保持云备份开启并连接互联网。打开“设置”“安全”“恢复码”，确认并输入 PIN。将新恢复码保存在安全的地方，然后点击“我已记下”以启用它。按照提示重新连接或同步。
- **手机也丢失了：**如果您没有恢复码副本，也没有其他能够解锁保险库的设备，我们就无法打开现有备份。在新手机上开启云备份并选择重新开始。

### 在哪里存储它

您的恢复代码与您的主密码一样敏感。按以下方式之一存储它：

- **密码管理器：**使用您信任的密码管理器。
- **物理备份：**将其写在纸上并存储在保险箱、银行保险箱或家中的安全位置。
- **离线文档：**保存到加密的外部驱动器或USB（从不同步到云）。
- **避免：**电子邮件、便签应用、未加密的云服务或屏幕截图。

### 重新生成您的代码

如果您认为恢复码已泄露，请保持云备份开启并连接互联网。打开“设置”“安全”“恢复码”，确认并输入 PIN。保存应用显示的新恢复码，然后点击“我已记下”以启用它。按照提示重新连接或同步。

**免责声明：**恢复码由您自行负责。如果丢失，Travel Document Vault 无法为您恢复或重置。请安全保管。不要将本应用作为重要文档的唯一备份方式。
