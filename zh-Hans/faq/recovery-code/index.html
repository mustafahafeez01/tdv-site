我的恢复代码是什么？

您的恢复代码是一个24字符的密码，用于加密您的云备份。如果丢失它，这些备份将无法恢复。我们不持有或重置它，因此请将其存储在安全的地方。

它的工作原理

它是什么

您的恢复代码是在启用云备份时生成的24字符密码。它看起来像：

XXXX-XXXX-XXXX-XXXX-XXXX-XXXX

此代码是从您的备份设置中数学推导出来的，是唯一能解密您在云上的加密保险库的密钥。我们生成一次并向您显示一次。之后，保护它的责任就在您身上。

为什么需要它

启用云备份时，您的整个保险库在离开手机之前，已在您的设备上使用AES-256-GCM加密。加密密钥源自您的恢复代码。没有恢复代码，备份在密码学上对我们也无法访问。

这是隐私保证。我们根本无法读取您的备份、按需解密或为您重置。如果您的恢复代码丢失，该备份将永远消失。这听起来很严厉，但这正是您想要的：您的隐私不仅是我们做出的承诺，而是我们无法违反的技术事实。

如果丢失它

如果您忘记恢复代码，无法恢复现有的云备份。您有两个选项：

  • 从您的手机恢复：如果代码仍存储在应用中（检查设置 - 云备份），将其复制到安全位置并保存。
  • 生成新的代码：禁用云备份并重新启用。这将创建新的恢复代码并丢弃现有备份。您重新开始。

在哪里存储它

您的恢复代码与您的主密码一样敏感。按以下方式之一存储它：

  • 密码管理器：Bitwarden、1Password、Apple Keychain或类似应用。这是最方便的选项。
  • 物理备份：将其写在纸上并存储在保险箱、银行保险箱或家中的安全位置。
  • 离线文档：保存到加密的外部驱动器或USB（从不同步到云）。
  • 避免：电子邮件、便签应用、未加密的云服务或屏幕截图。

重新生成您的代码

如果您认为恢复代码已被泄露，请关闭云备份，然后重新启用。应用生成新的恢复代码。您的旧加密备份被丢弃。这是设计的：恢复代码轮换意图上很少且有损，所以您不会轻易执行。

免责声明：您的恢复代码是您的唯一责任。如果丢失，Travel Document Vault无法恢复、重置或重新生成它。安全地存储它。不要仅依赖此应用作为关键文档的唯一备份系统。
