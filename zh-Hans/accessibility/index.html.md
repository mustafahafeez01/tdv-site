## 无障碍功能

### VoiceOver 支持

Travel Document Vault 的每个屏幕都完全支持 VoiceOver 语音。您可以使用手势、键盘、盲文和语音输出来导航、扫描文件、设置提醒和管理您的保险库。

- 所有交互元素的描述性标签
- 适当的标题层级，便于导航
- 有意义的按钮和控件描述
- 重要变化的状态公告

### 更大的文本（Dynamic Type）

应用中的所有文本都会随着您的系统文本大小偏好而缩放。将文本大小增加到 200% 或更多，应用布局会自动调整。

在您的设备上调整文本大小：**设置 → 无障碍 → 显示与文本大小 → 更大的文本**

### 深色界面

Travel Document Vault 支持亮色和深色两种模式。应用会自动匹配您的系统外观，或者您可以在设置中设置您偏好的主题。

选项：**系统（自动）**、**亮色**或**深色**。

### 充分的对比度

所有文本和交互元素都符合 WCAG AAA 对比度标准（正常文本 4.5:1，大文本 3:1）。高对比度颜色确保在所有光照条件下都可读。

我们的色彩系统为亮色和深色主题中的主要文本提供 15:1 以上的对比度。

### 区分不仅仅依靠颜色

重要信息永远不会仅通过颜色传达。状态指示符除了颜色外还使用图标、形状和文本标签。

- 有效文件的绿色复选标记（不仅仅是绿色）
- 即将过期文件的警告图标（不仅仅是黄色/橙色）
- 带 X 图标的错误指示符（不仅仅是红色）

### 减少动画

所有动画和动画效果都尊重您的减少动画偏好。启用时，动画会被最小化或移除，以防止晕动症和不适。

在您的设备上启用：**设置 → 无障碍 → 动画 → 减少动画**

## 其他无障碍考虑事项

44pt 触摸目标

所有交互元素都符合 Apple 的最小 44pt 触摸目标大小，便于点击。

键盘导航

使用连接到您设备的键盘浏览整个应用。

易读的字体

系统字体针对所有尺寸的易读性进行了优化。

清晰的错误消息

错误状态会通知 VoiceOver 并显示清晰、可操作的文本。
