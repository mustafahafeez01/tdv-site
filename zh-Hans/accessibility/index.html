为每个人而设计

Travel Document Vault 提供帮助您阅读、浏览和管理旅行文件的功能。以下是应用支持的功能。

无障碍功能

VoiceOver 支持

Travel Document Vault 支持配合 VoiceOver 使用。应用提供无障碍标签和屏幕阅读器播报。

  • 交互元素的描述性标签
  • 适当的标题层级，便于导航
  • 有意义的按钮和控件描述
  • 重要变化的状态公告

更大的文本（Dynamic Type）

应用中的文本会随系统文本大小偏好缩放。不同元素的缩放上限有所不同。

在您的设备上调整文本大小：设置 → 无障碍 → 显示与文本大小 → 更大的文本

深色界面

Travel Document Vault 支持亮色和深色两种模式。应用会自动匹配您的系统外观，或者您可以在设置中设置您偏好的主题。

选项：自动（系统）、浅色或深色。

充分的对比度

默认文本颜色注重清晰易读的对比度。高对比度颜色有助于在明亮和昏暗环境中阅读。

主要文本与默认浅色和深色背景之间具有较强的对比度。

状态提示不只依靠颜色

文档状态不会仅通过颜色显示。状态指示符除了颜色外还使用图标、形状和文本标签。

  • 有效文件的绿色复选标记（不仅仅是绿色）
  • 即将过期文件的警告图标（不仅仅是黄色/橙色）
  • 带 X 图标的错误指示符（不仅仅是红色）

减少动画

部分动画会遵循您的减少动态效果偏好。启用后，受支持的动画会减少或移除。

在您的设备上启用：设置 → 无障碍 → 动画 → 减少动画

其他无障碍考虑事项

44pt 触摸目标

通用控件样式以 iOS 的 44pt 和 Android 的 48dp 为目标；部分控件尺寸较小。

易读的字体

使用系统字体，并为不同元素设置相应的文字大小。

清晰的错误消息

无法保存表单等关键错误消息会通过 VoiceOver 播报，并以清晰、可操作的文字显示。
