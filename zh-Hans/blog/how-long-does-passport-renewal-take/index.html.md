- 要了解现在真正适用的数字，请咨询您自己的护照机构——英国护照办公室、美国国务院、澳大利亚护照办公室，或您所在国家的对应机构——而不是一篇博客文章。

## 美国护照更新需要多长时间？

美国国务院提供以下几种通道。处理时间会随需求和人手状况变化，申请前请务必在travel.state.gov上核实：

| 服务类型 | 您实际支付的是什么 |
|---|---|
| 常规 | 不收取额外费用，大致按接收顺序处理。适合没有临近出行安排的默认选择。 |
| 加急 | 额外付费可获得更靠前的排位。审核和材料要求与常规处理相同。 |
| 紧急（亲自在机构预约） | 出行真正迫在眉睫时，可直接前往地区护照机构。需要出行日期证明，通常只有在常规和加急通道显然来不及时才会安排。 |

如果您的出行真正迫在眉睫，可以获得紧急机构预约。在travel.state.gov查看当前资格条件并带上旅行证明——没有证明他们不会见您。

美国为符合条件的成年人提供在线更新计划。要符合条件，您必须更新在您16岁或以上时颁发的美国护照。查看travel.state.gov了解您是否符合条件以及该计划是否目前接受申请。

**公布的时间是平均值，而不是保证。**申请前请务必在travel.state.gov查看当前时间，因为在高峰需求期间，常规处理经常远超公布的估计。如果您的出行日期临近，加急处理的额外费用往往物有所值——它换来的确定性和日程安排灵活性通常远超这笔花费。

假设您在某国的旅游高峰季出行，护照的剩余有效期已经很紧张。支付更快通道的费用，换来的是确定性：无论当月标准积压有多长，您都能拿到队列中靠前的位置。而在繁忙时期仍坚持使用常规处理，则是在赌公布的预估时间依然反映现实——而这正是让人栽跟头的典型假设。

## 英国护照更新需要多长时间？

HM Passport Office负责处理英国的护照更新，并在其网站上公布当前的处理时间。

| 服务类型 | 内容 |
|---|---|
| 标准（在线） | 如果需要更多信息或面试则更长——查看GOV.UK了解当前时间 |
| 快速通道 | 额外费用；需在护照办公室亲自预约 |
| 在线数字更新 | 仅限符合条件的成年人；无需邮寄护照，通常较快 |
| 优惠服务（当日） | 有限名额；在特定办公室需要预约 |

英国为符合条件的、从**英国境内**申请的成年人提供数字更新服务。如果您符合条件，您不需要邮寄您的旧护照。该申请在线完成，通常比邮寄路线更快。 **如果您是住在国外的英国公民**（外籍人士），数字服务对您不可用。您必须使用GOV.UK上的海外护照服务，这需要将您的现有护照邮寄给HMPO。海外申请的处理时间可能比国内标准预估更长。查看GOV.UK了解您所在情况的正确服务，其在申请开始时询问您的位置。

公布的预估时间假设一切顺利进行。名字改变、第一本成人护照或任何需要额外检查的申请都会花费更长时间。儿童护照根本无法使用数字服务——他们仅经过标准流程。在申请前，查看GOV.UK了解与您所在情况相关的最新时间。

## 澳大利亚护照更新需要多长时间？

澳大利亚护照办公室为亲自申请或通过澳大利亚邮政申请的成年人公布当前的处理时间。

| 服务类型 | 内容 |
|---|---|
| 标准 | 在澳大利亚邮局或护照办公室申请；建议比出行日期提前充分申请 |
| 快速通道 | 额外付费即可比标准处理更快 |
| 优先 | 额外费用；适用资格条件 |

澳大利亚护照办公室公布当前的处理时间，并建议比出行日期提前充分申请。高峰期间处理时间仍可能延长——查看passports.gov.au了解最新时间。

儿童护照申请是另一回事。它们更复杂，耗时比成人更新要长，尤其是涉及父母同意要求的情况。

## 加拿大护照更新需要多长时间？

移民、难民和公民身份加拿大（IRCC）处理护照更新。申请前在IRCC官方页面查看当前处理时间是值得的。

| 服务类型 | 内容 |
|---|---|
| 邮件（Service Canada） | 另需加上双向邮寄时间；建议用于非紧急更新 |
| 亲自（护照加拿大办公室） | 在选定的办公室需要预约 |
| 紧急（临近出行） | 需要旅行证明；仅限亲自办理 |
| 特快（出行日期较近） | 需在护照办公室亲自办理 |

加拿大不提供在线护照更新。每份申请要么通过邮件进行，要么亲自通过护照加拿大办公室。这使该过程在后勤上更加要求——尤其是如果您住在某个偏远地区，最近的护照办公室距离很远。查看IRCC的页面了解最新处理时间。

## 加急护照更新提示：如何加快速度

无论您通过哪个国家进行更新，相同的错误一贯导致延误。留意这些常见的罪魁祸首：

- **表格不正确或不完整。**一个缺失的字段会将您的申请直接送回。先读一遍说明，填写表格，然后在提交前再读一遍。
- **不合规的照片。**护照照片规则很严格——背景颜色、头部大小、表情、没有眼镜。被拒绝的照片会冻结处理。如果您不确定，请专业完成。
- **缺失的支持文件。**名字改变、第一本成人护照和公民身份确认都需要额外文件。在申请前准备好一切，而不是之后。
- **时间紧张时邮寄。**邮件是不可预测的。如果您的旅行很近，尽可能使用亲自或加急路线，并在新护照到达前不要预订旅行。

## 您可以在护照更新待处理时旅行吗？

答案让大多数人惊讶。在大多数国家，您可以在更新待处理时旅行——您将使用您的旧（仍然有效的）护照以及护照机构的官方文件，确认您的申请正在进行中。

规则因国家而异：

- **美国：**在更新申请待处理时，您可以使用有效护照旅行。如果您将护照与更新申请一起提交（在某些情况下需要），您无法旅行直到您将其取回。如果您有迫在眉睫的旅行，请询问"由于旅行而加急"选项。
- **英国：**您可以在新护照处理中使用旧护照旅行——前提是旧护照仍然有效。一旦您将其发送给HMPO，您就无法使用它。不要在旅行迫在眉睫时提交护照。
- **澳大利亚：**原则相似——您的现有护照在处理更新时保持有效且可用，除非您已将其实际提交。
- **加拿大：**您可以在有效护照上在更新申请待处理时旅行，前提是您作为流程的一部分没有交出您的现有护照。
- **新西兰：**在大多数情况下，可以在不交出您的现有护照的情况下提交申请——查看内政部指导了解您的具体情况。
- **爱尔兰：**Passport Online和An Post更新服务在发出新护照之前不需要您交出现有护照。在申请前查看当前护照服务指导。

**关键的例外：**如果您的目的地国家需要单一入境签证，为旅行使用旧护照可能会使与其关联的签证无效。在旅行前，始终检查签证影响，在有新护照正在处理时使用旧护照。

## 如果您的旅行即将来临该怎么办

您已预订了未来几周的旅行，您的护照即将过期。不要惊慌——但要迅速行动：

1. **致电您的护照机构——不要仅仅浏览网站。**所有四个国家都有紧急和应急预约条款。电话将您连接到可以准确告诉您可用内容的真人。
2. **在致电前收集您的文件。**您需要迫在眉睫的旅行证明（显示日期的预订确认）、现有护照、照片和已填写的表格。准备好一切——紧急预约进展迅速。
3. **检查您的旅行保险政策。**某些政策涵盖加急护照更新的额外费用。大多数排除更新可预见的情况——但在花钱前值得看一下。
4. **询问重新安排您的旅行。**航空公司和酒店各不相同，但许多人将免除已记录护照紧急情况的改签费。不能保证，但询问不需要任何费用。

## 常见问题

### 美国护照更新需要多长时间？

我们无法在这里给您一个确定的数字，因为美国国务院的处理时间会随全年的需求和人手而变化。常规处理是默认队列；支付加急服务费用能让您在队列中排到更靠前的位置，而不是跳过任何审核环节。如果您的出行真的迫在眉睫，您可能符合在地区护照机构预约面谈的条件，但需要携带出行证明。申请前请在travel.state.gov查看当前数字。

### 英国护照更新需要多长时间？

英国护照办公室会公布其当前的处理时间，而且变动频繁，此刻在这里写下的任何数字，等您读到时很可能已经不准确。符合条件的、从英国境内申请的成年人可以使用数字更新服务，这不需要邮寄您的护照，但仍需要一张符合官方要求的照片。如果您从英国境外申请，则需要使用海外服务，这需要邮寄您现有的护照。紧急情况下，特定办公室提供快速通道和当日优惠预约。查看GOV.UK了解适用于您情况的数字。

### 澳大利亚护照更新需要多长时间？

澳大利亚护照办公室是了解当前时间唯一可靠的信息来源，因为时间会随申请量和季节变化。对于需要比标准队列更快的人，可以付费预订快速通道和优先处理。无论使用哪种方式，都请尽量提早申请——高峰期标准队列往往比公布的指引更长。申请前请查看passports.gov.au。

### 我可以在线更新护照吗？

美国为符合条件的、在16岁或以上时获得护照的成年人提供在线更新计划——查看travel.state.gov了解最新资格。英国为符合条件的、从英国境内申请的成年人提供数字更新选项——海外申请人必须使用单独的服务。澳大利亚和加拿大都需要为大多数更新亲自提交。始终检查您所在国家的官方网站了解最新资格规则。

### 如果我的护照即将过期而我已预订旅行，我应该怎么办？

一旦发现问题就立即申请，并支付您所在机构提供的最快通道费用。如果出行日期近到让您担心标准时间线赶不上，请不要只看网站，直接致电护照机构。这里介绍的所有国家都设有应急预约选项，但通常需要您主动电话询问。不要坐等标准流程碰巧赶上进度。

### 我可以在护照更新待处理时旅行吗？

在大多数情况下，可以——前提是您的现有护照仍然有效，并且您没有将其作为更新过程的一部分实际提交。美国、英国、澳大利亚、加拿大、新西兰和爱尔兰都允许在有效的现有护照待更新期间旅行。例外是如果您已将护照交给申请流程，在这种情况下您需要等待。在旅行前始终与您的特定护照机构核实，并考虑任何签证影响。
