为什么我开发了
Travel Document Vault

MH

Mustafa Hafeez

2026年1月3日

那天我在入境审查处，移民官看了看我女儿的护照，停顿了一下，然后抬头看着我。

"您知道这本护照七个月后就到期了吧？"他说，"提醒您一下——有些国家要求入境时护照有效期不得少于六个月。"

我道了谢。我们勉强过关了。但整个旅途中，我一直在想：如果他没有提醒，我根本不会注意到。七个月感觉还挺充裕的。订票前我也检查过护照，只是完全忽略了大多数国家都要求的六个月有效期规定。

这次险些出事的经历让我久久难忘。我早已为全家人的护照到期日设置了日历提醒，以为这样就够了。但我并没有真正去核对日期，只是依赖那些提醒。而一旦有人护照续签，我又得更新提醒、更新存在 Google Drive 里的扫描件，还得祈祷自己没有遗漏什么。

那种揪心的感觉——意识到自己差点毁掉一次家庭旅行却浑然不知——正是我开发这款应用的原因。

那些隐形的负担

如果你是家里负责管理证件的那个人，你一定懂这种感受。

你不只是在存文件。你脑子里一直挂着一张看不见的清单：谁的护照什么时候到期，孩子入学需要哪些材料，哪些国家有六个月有效期的规定，旅行保险到底续签了还是只是打算续签。

单独一项检查并不费时。查一份护照扫描件、读一下到期日、确认出行时有效期够不够六个月——也许两三分钟。但乘以四位家庭成员，再加上埋在邮件里的保险单、你不确定是否还有效的驾照，在出发前一晚11点你已经耗掉了十五到二十分钟。

这还是在一切都在你以为的地方的前提下。如果你要在几千张照片里翻找护照扫描件，或者在三个不同的云端文件夹里找正确的文件，那要花更长时间——压力也会迅速累积。

没有人看见这些付出。没有人递给你一张清单。你只能一个人扛着。

我并不想开发一款旅行应用。我只是想把这些东西从脑子里卸下来。

我曾尝试过的方法

在动手开发之前，我什么都试过了。

云端存储？存文件没问题，但到期日一点用都没有。我还是得手动打开每份文件，自己心算日期。

日历提醒？也试过。在每本护照到期前六个月设了通知。但扫描件在一个地方，提醒在另一个地方，每当我在出发前一晚11点需要查东西，我在三个应用之间来回跳转，试图拼凑完整信息。

密码管理器？有些人确实用它来存证件扫描件。但它们是为密码设计的，不是为到期日设计的。更不会在你孩子的护照快让旅行泡汤时提醒你。

最终让我想通的是：我不需要另一个存 PDF 的地方。我需要的是一个能在到期前六个月提醒我的工具——而不是在到期当天。一个能让我一眼看出"我们八月出发，大家的护照能覆盖到二月吗？"而无需查签证规定或心算的工具。

而且它必须支持离线使用。因为我可能在机场，或者困在 Wi-Fi 很差的酒店大堂，急需出示证件副本——而那恰恰是云端应用加载不出来的时候。

于是我开发了正是我所需要的东西

Travel Document Vault 只做一件事：把所有东西放在一个地方，让你不再需要操心，直到应用告诉你该关注了。

扫描一次证件，应用读取到期日（你再核对一遍）。提醒自动安排好：提前六个月、三个月、六周、一个月、两周，一直到到期前一天。

每位家庭成员一个档案，所有证件集中存放。需要确认能不能出行时，打开应用就知道了。是真的知道，不是"大概"或"应该吧"——你真的清楚。

酒店要你的护照复印件、使馆需要你的信息、租车柜台要查你的驾照，一键分享搞定。不用翻找，不需要 Wi-Fi。所有东西都在那里，随时可用。

这才是真正的回报：你找回了脑子里的空间。那种隐形的精神负担——那种持续的低频焦虑"我是不是忘了什么？"——消失了。应用替你记着，你不用再操心。

不只是护照

开始使用之后，我发现有太多其他证件也在悄悄地到期。

海外生活的工作许可。每年需要续签的签证和居留证。驾照。需要证明保障范围的医疗保险。旅行保险单。孩子的身份证。

它们都有到期日。它们都会在最不凑巧的时候出问题。没有人提醒你，直到太迟——或者你已经站在使馆门口，才发现签证上个月就过期了。

这款应用全都能处理。任何有到期日的东西——护照、签证、工作许可、保险、驾照，以及你家人需要的任何证件——一个地方，统一追踪，整齐归档。

在海外遇到麻烦时

护照在海外每天都有遗失或被盗的情况，从另一个国家补办护照是件耗时的事。如果不幸发生在你身上，你不会两手空空。

证件号码、到期日、清晰的扫描件——在你需要报警或联系使馆时，一切都已备好。它无法替代原件，但能让你迅速行动。无需 Wi-Fi，无需慌乱。

以隐私为设计核心

开发初期，我做了一个明确的决定：你的证件属于你，它们留在你那里。就这么简单。

Travel Document Vault 完全自给自足：

  • 无需注册账户
  • 不上传至服务器
  • 在你的设备上加密存储

扫描证件时，文字识别（OCR）在你的设备上本地运行。所有内容都留在你的手机上。没有任何内容会上传至任何服务器。

有些人希望应用能全端同步。但对于护照和身份证，我想要一个更简单的模式：你的手机就是保险库。你可以随时导出你的副本，毕竟，它们是你的东西。

为什么是一次性付款而非订阅

Travel Document Vault 是那种一次设置好就不用管的东西。它在后台静静追踪到期日，直到你真正需要它。这就是它的全部意义。

订阅制对此完全没有道理。如果我停止付费，我就得导出所有东西，找另一个应用，迁移证件，重建所有提醒。万一忘了续订？我会在最需要它的时候失去访问权——站在值机柜台，发现孩子护照只剩四个月有效期，却打不开我存好的扫描件。

当你购买这款应用，它就是你的了。证件留在你的设备上。提醒持续运作。无需续费，无需导出，没有锁定。它就在后台静静工作，直到你需要它。

免费版提供一个档案、五份文件、OCR、提醒功能和 PIN 锁。专业版通过一次性付款解锁无限档案和无限文件。买断一次，永久包含所有 v1.x 版本更新。就这样。

为何存在

我开发 Travel Document Vault，是因为我再也不想做那个在登机口焦虑翻手机的家长。

我想陪孩子们一起指着飞机说"快看"，而不是在应用之间来回切换找对应的证件。我想在出门前就真正确定——不是"大概没问题"，而是真的确定——所有东西都已备齐。

如果你是家里那个凡事都要再确认一遍的人，那个保管文件夹、默默操心以免别人担心的人——这就是我为你开发这款应用背后的故事。

少一件需要操心的事。

首先为个人需求而开发。无账户。不上传至服务器。
