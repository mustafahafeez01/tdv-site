# What is My Recovery Code? | Travel Document Vault

> Your recovery code unlocks your encrypted cloud backups. What it is, what happens if you lose it, and how to store it safely.

Source: https://traveldocumentvault.com/faq/recovery-code/

---

Your recovery code is a 24-character passphrase that unlocks your cloud encryption keys. If you lose every copy of the code and access to every device that can still unlock the vault, we cannot recover those backups. We do not hold or reset it, so store it somewhere safe.

## How it works

### What it is

Your recovery code is a 24-character passphrase generated when you set your PIN. It looks like:

XXXX-XXXX-XXXX-XXXX-XXXX-XXXX

Your recovery code unlocks the encryption keys needed to restore your cloud backup with Pro. The app generates it when you set your PIN and shows it once. Save a copy somewhere safe.

### Why you need it

With Pro cloud backup, the app encrypts your document contents on your device using AES-256-GCM before upload. Your recovery code unlocks the cloud encryption keys. You need it to restore a backup. We do not hold a copy.

We cannot decrypt or reset your cloud backup for you. If you lose every copy of your recovery code and access to every device that can still unlock the vault, we cannot recover that backup.

### If you lose it

If you forget your recovery code, what you can do depends on whether you still have a device that can unlock the vault and its PIN:

- **Generate a new one on your phone:** Keep cloud backup enabled and connect to the internet. Open Settings, Security, Recovery Code, confirm, and enter your PIN. Save the new code somewhere safe, then tap the saved-code confirmation to activate it. Follow any prompts to reconnect or sync.
- **Lost the phone too:** If you have no copy of the recovery code and no other device that can still unlock the vault, we cannot open the existing backup. Turn on cloud backup on your new phone and choose to start fresh.

### Where to store it

Your recovery code is as sensitive as your master password. Store it in one of these ways:

- **Password manager:** Use a password manager you trust.
- **Physical backup:** Write it on paper and store in a safe, safety deposit box, or secure location at home.
- **Offline document:** Save to an encrypted external drive or USB (never cloud-synced).
- **Avoid:** Email, Notes app, unencrypted cloud services, or screenshots.

### Regenerating your code

If you think your recovery code is compromised, keep cloud backup enabled and connect to the internet. Open Settings, Security, Recovery Code, confirm, and enter your PIN. Save the new code shown by the app, then tap the saved-code confirmation to activate it. Follow any prompts to reconnect or sync.

**Disclaimer:** Your recovery code is your sole responsibility. Travel Document Vault cannot recover or reset it for you if lost. Store it securely. Do not rely on this app as your only backup system for critical documents.
