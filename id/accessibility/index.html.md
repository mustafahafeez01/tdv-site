# Fitur Aksesibilitas | Travel Document Vault

> Travel Document Vault dibangun untuk semua orang. Pelajari tentang fitur VoiceOver, Dynamic Type, Dark Mode, dan Reduce Motion kami, dalam aplikasi yang bekerja offline dan menyimpan dokumen Anda di perangkat Anda sendiri.

Source: https://traveldocumentvault.com/id/accessibility/

---

## Fitur Aksesibilitas

### Dukungan VoiceOver

Setiap layar di Travel Document Vault sepenuhnya disertakan narasi dengan VoiceOver. Navigasi, pindai dokumen, atur pengingat, dan kelola brankas Anda menggunakan gestur, keyboard, braille, dan keluaran ucapan.

- Label deskriptif untuk semua elemen interaktif
- Hierarki heading yang tepat untuk navigasi mudah
- Deskripsi tombol dan kontrol yang bermakna
- Pengumuman status untuk perubahan penting

### Teks Lebih Besar (Dynamic Type)

Semua teks dalam aplikasi diskalakan dengan preferensi ukuran teks sistem Anda. Tingkatkan ukuran teks hingga 200% atau lebih, dan tata letak aplikasi menyesuaikan secara otomatis.

Sesuaikan ukuran teks di **Pengaturan → Aksesibilitas → Tampilan & Ukuran Teks → Teks Lebih Besar** di perangkat Anda.

### Antarmuka Gelap

Travel Document Vault mendukung mode Terang dan Gelap. Aplikasi secara otomatis cocok dengan tampilan sistem Anda, atau Anda dapat mengatur tema pilihan Anda di Pengaturan.

Opsi: **Sistem (Otomatis)**, **Terang**, atau **Gelap**.

### Kontras yang Cukup

Semua teks dan elemen interaktif memenuhi standar kontras WCAG AAA (4,5:1 untuk teks normal, 3:1 untuk teks besar). Warna kontras tinggi memastikan keterbacaan dalam semua kondisi cahaya.

Sistem warna kami menyediakan rasio kontras 15:1+ untuk teks utama dalam tema terang dan gelap.

### Bedakan Tanpa Warna Saja

Informasi penting tidak pernah disampaikan hanya dengan warna. Indikator status menggunakan ikon, bentuk, dan label teks selain warna.

- Centang hijau untuk dokumen valid (bukan hanya warna hijau)
- Ikon peringatan untuk dokumen yang akan kedaluwarsa (bukan hanya warna kuning/oranye)
- Indikator kesalahan dengan ikon X (bukan hanya warna merah)

### Gerakan yang Berkurang

Semua animasi dan efek gerakan menghormati preferensi Reduce Motion Anda. Jika diaktifkan, animasi diminimalkan atau dihapus untuk mencegah penyakit gerakan dan ketidaknyamanan.

Aktifkan di **Pengaturan → Aksesibilitas → Gerakan → Kurangi Gerakan** di perangkat Anda.

## Pertimbangan Aksesibilitas Tambahan

Target Sentuh 44pt

Semua elemen interaktif memenuhi ukuran target sentuh minimum 44pt Apple untuk pengetukan mudah.

Navigasi Keyboard

Navigasi seluruh aplikasi menggunakan keyboard yang terhubung ke perangkat Anda.

Font Dapat Dibaca

Font sistem dioptimalkan untuk keterbacaan di semua ukuran.

Pesan Kesalahan yang Jelas

Status kesalahan diumumkan ke VoiceOver dan ditampilkan dengan teks yang jelas dan dapat ditindaklanjuti.
