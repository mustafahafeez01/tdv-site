# アクセシビリティ機能 | Travel Document Vault

> Travel Document Vault はすべての人のために作られています。VoiceOver、Dynamic Type、ダークモード、Reduce Motion に対応し、オフラインで動作し、書類はお使いのデバイスに保存されます。

Source: https://traveldocumentvault.com/ja/accessibility/

---

## アクセシビリティ機能

### VoiceOver 対応

Travel Document Vault のすべての画面は VoiceOver で完全にサポートされています。ジェスチャー、キーボード、ブレイルおよび音声出力を使用して、書類をスキャンしたり、リマインダーを設定したり、金庫を管理したりできます。

- すべてのインタラクティブ要素に説明的なラベル
- 簡単なナビゲーションのための適切な見出しの階層
- わかりやすいボタンとコントロールの説明
- 重要な変更のステータスアナウンスメント

### 大きなテキスト（Dynamic Type）

アプリ内のすべてのテキストはシステムテキストサイズの設定に応じてスケーリングされます。テキストサイズを 200% 以上に増やすと、アプリのレイアウトが自動的に調整されます。

デバイスの **設定 → アクセシビリティ → ディスプレイとテキストサイズ → 大きいテキスト** でテキストサイズを調整してください。

### ダークインターフェース

Travel Document Vault はライトモードとダークモードの両方をサポートしています。アプリはシステムの外観に自動的に一致するか、設定でお好みのテーマを設定できます。

オプション：**システム（自動）**、**ライト**、または **ダーク**。

### 十分なコントラスト

すべてのテキストおよびインタラクティブ要素は WCAG AAA コントラスト基準（通常テキスト 4.5:1、大きいテキスト 3:1）を満たしています。高いコントラスト色により、すべての照明条件で読みやすさが保証されます。

当社のカラーシステムはライトテーマとダークテーマの両方で、主要テキストに 15:1 以上のコントラスト比を提供します。

### 色だけに頼らない情報表示

重要な情報は色だけで伝えられることはありません。ステータスインジケーターは色に加えてアイコン、形、テキストラベルを使用します。

- 有効なドキュメントの緑色のチェックマーク（単なる緑色ではなく）
- 有効期限間近のドキュメントの警告アイコン（単なる黄色/オレンジ色ではなく）
- X アイコン付きのエラーインジケーター（単なる赤色ではなく）

### モーション削減

すべてのアニメーションとモーション効果は Reduce Motion 設定を尊重します。有効にすると、動きのある症状や不快感を防ぐためにアニメーションが最小化または削除されます。

デバイスの **設定 → アクセシビリティ → モーション → モーション削減** で有効にしてください。

## その他のアクセシビリティの配慮

44pt タッチターゲット

すべてのインタラクティブ要素は、簡単にタップできるように Apple の最小 44pt タッチターゲットサイズを満たしています。

キーボードナビゲーション

デバイスに接続されたキーボードを使用して、アプリ全体をナビゲートできます。

読みやすいフォント

すべてのサイズで読みやすさに最適化されたシステムフォント。

明確なエラーメッセージ

エラー状態は VoiceOver にアナウンスされ、明確で実用的なテキストで表示されます。
