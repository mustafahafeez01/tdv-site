# アクセシビリティ機能 | Travel Document Vault

> Travel Document Vault はすべての人のために作られています。VoiceOver、Dynamic Type、ダークモード、Reduce Motion に対応し、オフラインで動作し、書類はお使いのデバイスに保存されます。

Source: https://traveldocumentvault.com/ja/accessibility/

---

## アクセシビリティ機能

### VoiceOver 対応

Travel Document VaultはVoiceOverでの利用に対応するよう作られています。アクセシビリティラベルやスクリーンリーダー向けの読み上げ通知を備えています。

- 操作できる要素に説明的なラベル
- 簡単なナビゲーションのための適切な見出しの階層
- わかりやすいボタンとコントロールの説明
- 重要な変更のステータスアナウンスメント

### 大きなテキスト（Dynamic Type）

アプリ内のテキストは、システムの文字サイズ設定に応じて拡大されます。拡大できる上限は要素によって異なります。

デバイスの **設定 → アクセシビリティ → ディスプレイとテキストサイズ → 大きいテキスト** でテキストサイズを調整してください。

### ダークインターフェース

Travel Document Vault はライトモードとダークモードの両方をサポートしています。アプリはシステムの外観に自動的に一致するか、設定でお好みのテーマを設定できます。

オプション：**自動（システム設定）**、**ライト**、または **ダーク**。

### 十分なコントラスト

標準の文字色は、読みやすいコントラストを考慮して選んでいます。コントラストの高い配色は、明るい場所でも暗い場所でも読みやすさを助けます。

主要なテキストは、標準のライトモードとダークモードの背景に対して高いコントラストがあります。

### 書類の状態は色以外でも表示

書類の状態は色だけで伝えられることはありません。ステータスインジケーターは色に加えてアイコン、形、テキストラベルを使用します。

- 有効なドキュメントの緑色のチェックマーク（単なる緑色ではなく）
- 有効期限間近のドキュメントの警告アイコン（単なる黄色/オレンジ色ではなく）
- X アイコン付きのエラーインジケーター（単なる赤色ではなく）

### モーション削減

一部のアニメーションはReduce Motion設定に対応しています。有効にすると、対応するアニメーションの動きを抑えたり、省略したりします。

デバイスの **設定 → アクセシビリティ → モーション → モーション削減** で有効にしてください。

## その他のアクセシビリティの配慮

44pt タッチターゲット

共通の操作要素のスタイルでは、iOSは44pt、Androidは48dpを目安にしています。一部の操作要素はこれより小さくなっています。

読みやすいフォント

システムフォントを使用し、要素ごとに文字サイズを設定しています。

明確なエラーメッセージ

フォームをまだ保存できない場合など、主なエラーメッセージはVoiceOverで読み上げられ、対処方法が分かるテキストで表示されます。
