# バックアップについて: ローカルバックアップ、ボルトエクスポート、クラウドバックアップ | Travel Document Vault

> Travel Document Vaultがあなたのデータを保護する3つの方法についての明確な説明です: 自動ローカルバックアップ、Vault Export (.tdvault)、およびオプションのProクラウドバックアップ (iCloudまたはGoogle Drive)。

Source: https://traveldocumentvault.com/ja/faq/backup-explained/

---

Travel Document Vaultは3層の保護を提供します。ここでは、各層が正確に何を行い、誰のためのもので、どのように復元するかを説明します。

## 3つのメカニズム、1つの目標

Travel Document Vaultは3層の保護を提供します: (1) 自動ローカルバックアップ。デバイス上で数分ごとに作成され、無料です。(2) Vault Export。無料の手動暗号化バックアップファイル (.tdvault) で、任意の場所に保存できます。(3) Cloud Backup。Proオプションで、エンドツーエンド暗号化されたコピーをあなた自身のiCloudまたはGoogle Driveに保持します。

- **自動ローカルバックアップ**、バックグラウンドで静かに実行され、アクションは不要です。
- **Vault Export (.tdvault)**、任意の場所に保存できるポータブルな暗号化ファイル。
- **クラウドバックアップ (Pro)**、あなた自身のiCloudまたはGoogle Driveに自動的に暗号化されたコピーが保存されます。

## 一目でわかる比較

## 自動ローカルバックアップ

アプリを開いて変更を加えると、数分ごとに金庫のスナップショットが自動で作成されます。操作は不要です。直近のスナップショットをいくつか保持し、古いものは容量を節約するために削除します。Vault Exportでは、デバイス外に保存できる持ち運び可能な暗号化ファイルを作成します。

設定では、「最後のバックアップ: 2時間前、12ドキュメント」のような行が表示されます。これにより、最新のスナップショットの年齢と、キャプチャされたドキュメント数がわかります。利用できる最新のローカルスナップショットを示します。ローカルスナップショットには、添付ファイルの独立したコピーは含まれません。

**復元するには:** 設定に移動してから、ローカルバックアップを復元を選択します。リストからスナップショットを選択して確認します。復元すると、現在のデータがスナップショットの内容に置き換わります。

これらのローカルスナップショットはデバイスに保存されます。システムバックアップ (iCloud Backup、Google Backup) はアプリを再インストールしますが、通常のスマートフォンのバックアップでは端末固有の暗号鍵が移行されないため、新しいスマートフォンでは復元できません。Vault Exportには、この鍵をパスワードで暗号化したコピーが含まれます。ボルトを移動するには、クラウドバックアップ (Pro) または無料のVault Exportを使用します。

## Vault Export (.tdvault)、すべての人に無料

Vault Exportは、対応する金庫の記録と利用可能な添付ファイルを、一つの暗号化されたパスワード付きファイルにまとめます。各エクスポートにはサイズの上限があります。保存場所を選択できます: ファイルアプリ、iCloud Drive、Google Drive、またはAirDropやメール経由で共有できます。

ファイルはアプリから離れる前にデバイス上で暗号化されます。エクスポート時に設定したパスワードのみがアンロックできます。

**エクスポートするには:** 設定、金庫をエクスポート、プロンプトに従って目的地を選択します。

**復元するには：** 「設定」の「バックアップをインポート」で.tdvaultファイルを選択し、確認してからパスワードを入力します。インポートすると、スマートフォン内の既存データがすべて置き換わります。対応デバイスで利用でき、iOSとAndroidの間でも移行できます。対応する金庫の項目と一部の設定が保存されますが、見つからない添付ファイルや読み取れないメモは省かれる場合があります。取り込んだ書類とリマインダーを確認してください。アプリロックやその他のデバイス設定は端末内に留まります。

これはすべてのユーザーに無料です。Proの購入は不要です。

## クラウドバックアップ (Pro)

クラウドバックアップはProの機能です。有効にすると、ご自身のiCloud（iOS）またはGoogle Drive（Android）に自動でコピーを保存します。アプリを開いて通信に接続している間に更新されます。当社はバックアップを受け取りません。書類の内容は暗号化されますが、デバイス名、件数、タイムスタンプなどのメタデータは暗号化されません。

書類の内容は、アップロード前に端末上でAES-256-GCMによってエンドツーエンド暗号化されます。クラウドの暗号鍵は、PIN設定時にアプリが生成する24文字の回復コードで解除します。回復コードを安全な場所に保管してください。コードのコピーをすべて失い、金庫を解除できるすべてのデバイスにもアクセスできなくなった場合、当社は暗号化バックアップを復旧できません。

**復元するには：** 同じプラットフォーム上の対応デバイスで、同じApple IDまたはGoogleアカウントを使います。バックアップをオフにした状態で「設定」から「クラウドバックアップ」を開きます。「バックアップから復元」を選び、バックアップを選択して回復コードを入力し、確認してください。復元すると端末内の金庫の内容が置き換わります。

クラウドバックアップは、アプリを開いて通信に接続している間に自動で実行されます。同じプラットフォーム上の対応デバイスと同じクラウドアカウントを使い、「設定」から回復コードで復元できます。

## どれを使用すべきですか?

簡潔な答え: すべてを使用してください。

自動ローカルバックアップは、利用可能なスナップショットがあれば、最近の金庫の記録を復旧する助けになります。アプリを開いている間に実行されるもので、書類の独立したバックアップの代わりにはなりません。

Vault Exportは、デバイス変更、主要なアプリアップデート、またはデバイスから独立した安全な場所に保存されたポータブルコピーが必要な場合に適切な選択肢です。少なくとも1回実行して、ファイルを安全な場所に保存してください。

クラウドバックアップ (Pro) は、ファイルを手動で管理する必要なく、自動的なオフデバイス保護が必要な場合に適切な選択肢です。同じプラットフォーム上の対応スマートフォンに移行する際は、同じクラウドアカウントを使い、復元の手順でバックアップを選択して回復コードを入力し、確認します。復元すると端末内の金庫の内容が置き換わります。

単一のレイヤーは、他を使用しない理由ではありません。クラウドアカウントは失われる可能性があり、リカバリーコードは忘れられる可能性があり、電話はローカルバックアップが実行される前に盗まれる可能性があります。3つすべての組み合わせにより、最強の保護が得られます。
