リカバリーコードとは

回復コードは、クラウドの暗号鍵を解除する24文字のパスフレーズです。コードのコピーをすべて失い、金庫を解除できるすべてのデバイスにもアクセスできなくなった場合、当社はバックアップを復旧できません。当社はコードを保有せず、リセットもできないため、安全な場所に保管してください。

仕組み

リカバリーコードについて

回復コードは、PINを設定したときに生成される24文字のパスフレーズです。形式は次のとおりです。

XXXX-XXXX-XXXX-XXXX-XXXX-XXXX

回復コードは、Proのクラウドバックアップを復元するために必要な暗号鍵を解除します。アプリはPIN設定時にコードを生成し、一度だけ表示します。コピーを安全な場所に保管してください。

必要な理由

Proのクラウドバックアップでは、アップロード前に書類の内容を端末上でAES-256-GCMによって暗号化します。回復コードはクラウドの暗号鍵を解除し、バックアップの復元に必要です。当社はコピーを保有しません。

当社はクラウドバックアップをお客様の代わりに復号したり、リセットしたりできません。回復コードのコピーをすべて失い、金庫を解除できるすべてのデバイスにもアクセスできなくなった場合、当社はバックアップを復旧できません。

紛失した場合

回復コードを忘れた場合にできることは、金庫を解除できるデバイスとそのPINが残っているかどうかによって異なります。

  • スマートフォンで新しいコードを生成：クラウドバックアップを有効にしたままインターネットに接続します。「設定」から「セキュリティ」、「回復コード」を開き、確認してPINを入力します。新しいコードを安全な場所に保管し、保存したことを確認するボタンをタップして有効にします。再接続や同期の案内に従ってください。
  • スマートフォンも紛失した場合：回復コードのコピーも、金庫を解除できる他のデバイスもない場合、当社は既存のバックアップを開けません。新しいスマートフォンでクラウドバックアップを有効にし、「新規開始」を選んでください。

保管場所

リカバリーコードはマスターパスワードと同じくらい機密です。次のいずれかの方法で保管してください。

  • パスワードマネージャー：信頼できるパスワードマネージャーを使ってください。
  • 物理的バックアップ紙に書いて金庫、安全保管庫、または自宅の安全な場所に保管します。
  • オフラインドキュメント暗号化された外部ドライブまたは USB に保存します（クラウド同期なし）。
  • 避けるべき方法メール、メモアプリ、暗号化されていないクラウドサービス、またはスクリーンショット。

コードの再生成

回復コードが漏れたと思われる場合は、クラウドバックアップを有効にしたままインターネットに接続してください。「設定」から「セキュリティ」、「回復コード」を開き、確認してPINを入力します。アプリに表示された新しいコードを保管し、保存したことを確認するボタンをタップして有効にします。再接続や同期の案内が出た場合は、それに従ってください。

免責事項リカバリーコードはあなたの唯一の責任です。Travel Document Vault は、紛失した場合、コードをお客様の代わりに復旧したり、リセットしたりできません。安全に保管してください。このアプリを重要なドキュメントの唯一のバックアップシステムとして頼らないでください。

ボルトを保護する準備はできていますか?

Travel Document Vaultは無料でダウンロードできます。Proではご自身のiCloudまたはGoogle Driveへの暗号化バックアップを利用できます。有効にする前に回復コードを保管してください。
