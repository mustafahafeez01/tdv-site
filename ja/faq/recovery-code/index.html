リカバリーコードとは

リカバリーコードは、クラウドバックアップを暗号化する24文字のパスフレーズです。紛失すると、これらのバックアップは復旧できなくなります。私たちはこれを保有またはリセットしないため、安全な場所に保管してください。

仕組み

リカバリーコードについて

リカバリーコードは、クラウドバックアップを有効にするときに生成される24文字のパスフレーズです。形式は次のようになります。

XXXX-XXXX-XXXX-XXXX-XXXX-XXXX

このコードはあなたのバックアップ設定から数学的に導出され、クラウドに暗号化されたボルトを復号化できる唯一のキーです。私たちはそれを1回生成してあなたに1回表示します。その後、それを安全に保つ責任はあなたにあります。

必要な理由

クラウドバックアップを有効にすると、あなたのボルト全体は、デバイス上で AES-256-GCM を使用して暗号化されてから、電話から送信されます。暗号化キーはあなたのリカバリーコードから導出されます。リカバリーコードがなければ、バックアップは暗号的にアクセスできません。これは私たちにとってもそうです。

これはプライバシーの保証です。私たちはあなたのバックアップを読み取ったり、必要に応じて復号化したり、リセットしたりすることはできません。リカバリーコードを紛失した場合、そのバックアップは永久に失われます。厳しく聞こえるかもしれませんが、これはまさにあなたが望んでいるものです。あなたのプライバシーは、私たちが約束するだけでなく、私たちが違反することのできない技術的事実です。

紛失した場合

リカバリーコードを忘れた場合、既存のクラウドバックアップは復旧できません。2つの選択肢があります。

  • 電話から復元するコードがアプリに保存されている場合（設定 - クラウドバックアップを確認）、安全な場所にコピーして保存します。
  • 新しいコードを生成するクラウドバックアップを無効にして再度有効にします。これにより新しいリカバリーコードが作成され、既存のバックアップが破棄されます。新たに始まります。

保管場所

リカバリーコードはマスターパスワードと同じくらい機密です。次のいずれかの方法で保管してください。

  • パスワードマネージャーBitwarden、1Password、Apple Keychain、または同様のもの。これが最も便利なオプションです。
  • 物理的バックアップ紙に書いて金庫、安全保管庫、または自宅の安全な場所に保管します。
  • オフラインドキュメント暗号化された外部ドライブまたは USB に保存します（クラウド同期なし）。
  • 避けるべき方法メール、メモアプリ、暗号化されていないクラウドサービス、またはスクリーンショット。

コードの再生成

リカバリーコードが侵害されていると思われる場合は、クラウドバックアップをオフにしてオンに戻してください。アプリが新しいリカバリーコードを生成します。古い暗号化されたバックアップは破棄されます。これは仕様です。リカバリーコードローテーションは意図的にまれで損失的であるため、軽々しく行いません。

免責事項リカバリーコードはあなたの唯一の責任です。Travel Document Vault は、紛失した場合、コードを復旧、リセット、または再生成できません。安全に保管してください。このアプリを重要なドキュメントの唯一のバックアップシステムとして頼らないでください。
