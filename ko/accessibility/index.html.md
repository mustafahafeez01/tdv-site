# 접근성 기능 | Travel Document Vault

> Travel Document Vault는 모든 사람을 위해 만들어졌습니다. VoiceOver, 동적 텍스트, 다크 모드 및 움직임 감소 기능을 지원하며, 오프라인으로 작동하고 문서는 기기에만 보관됩니다.

## 접근성 기능

### VoiceOver 지원

Travel Document Vault는 VoiceOver와 함께 사용할 수 있도록 설계되었습니다. 접근성 레이블과 화면 읽기 프로그램의 안내 기능을 제공합니다.

- 대화형 요소의 설명 레이블
- 쉬운 탐색을 위한 올바른 제목 계층 구조
- 의미 있는 버튼 및 컨트롤 설명
- 중요한 변경에 대한 상태 공지

### 더 큰 텍스트(동적 텍스트)

앱의 텍스트는 시스템 텍스트 크기 설정에 따라 조정됩니다. 텍스트 확대 한도는 요소마다 다릅니다.

기기에서 **설정 → 접근성 → 디스플레이 및 텍스트 크기 → 더 큰 텍스트**에서 텍스트 크기를 조정합니다.

### 다크 인터페이스

Travel Document Vault는 라이트 모드와 다크 모드를 모두 지원합니다. 앱이 시스템 모양과 자동으로 일치하거나 설정에서 선호하는 테마를 설정할 수 있습니다.

옵션: **자동(시스템)**, **라이트**, 또는 **다크**.

### 충분한 대비

기본 텍스트 색상은 읽기 쉬운 대비를 고려하여 선택되었습니다. 대비가 높은 색상은 밝거나 어두운 환경에서 가독성에 도움이 됩니다.

주요 텍스트는 기본 라이트 및 다크 배경에서 뚜렷한 대비를 제공합니다.

### 색상 외의 표시로도 상태 전달

문서 상태는 색상만으로 표시되지 않습니다. 상태 표시기는 색상 외에 아이콘, 모양 및 텍스트 레이블을 사용합니다.

- 유효한 문서에 대한 녹색 체크 표시(녹색 색상만 아님)
- 만료되는 문서의 경고 아이콘(노란색/주황색 색상만 아님)
- X 아이콘이 있는 오류 표시기(빨간색 색상만 아님)

### 움직임 감소

일부 애니메이션은 움직임 감소 설정을 따릅니다. 설정을 켜면 지원되는 애니메이션이 줄어들거나 제거됩니다.

기기에서 **설정 → 접근성 → 모션 → 움직임 감소**에서 활성화합니다.

## 추가 접근성 고려 사항

44pt 터치 대상

공통 컨트롤 스타일은 iOS에서 44pt, Android에서 48dp를 목표로 하며, 일부 컨트롤은 이보다 작습니다.

읽기 쉬운 글꼴

요소별로 텍스트 크기를 설정한 시스템 글꼴.

명확한 오류 메시지

아직 저장할 수 없는 양식과 같은 주요 오류 메시지는 VoiceOver로 안내되며, 취할 조치를 알 수 있는 명확한 텍스트로 표시됩니다.
