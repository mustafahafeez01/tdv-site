내 복구 코드란 무엇입니까?

복구 코드는 클라우드 백업을 암호화하는 24자리 암호문입니다. 분실하면 해당 백업은 복구할 수 없습니다. 당사는 이를 보유하거나 리셋하지 않으므로 안전한 장소에 보관합시다.

작동 방식

복구 코드란 무엇입니까

복구 코드는 클라우드 백업을 활성화할 때 생성되는 24자리 암호문입니다. 다음과 같이 표시됩니다.

XXXX-XXXX-XXXX-XXXX-XXXX-XXXX

이 코드는 백업 설정에서 수학적으로 유도되며 클라우드의 암호화된 저장소를 암호 해독할 수 있는 유일한 키입니다. 당사는 한 번 생성하고 한 번만 표시합니다. 그 이후로 이를 안전하게 보관할 책임은 귀하에게 있습니다.

왜 필요합니까

클라우드 백업을 활성화하면 전체 저장소는 휴대폰을 떠나기 전에 AES-256-GCM을 사용하여 기기에서 암호화됩니다. 암호화 키는 복구 코드에서 유도됩니다. 복구 코드 없으면 백업은 암호학적으로 접근할 수 없으며, 당사라도 마찬가지입니다.

이는 개인정보 보호 보장입니다. 당사는 백업을 읽거나, 온디맨드로 암호 해독하거나, 리셋할 수 없습니다. 복구 코드가 분실되면 해당 백업은 영원히 사라집니다. 이는 엄격해 보이지만 정확히 원하는 것입니다. 귀하의 개인정보 보호는 당사가 하는 약속이 아니라 당사가 위반할 수 없는 기술적 사실입니다.

분실했을 경우

복구 코드를 잊어버렸으면 기존 클라우드 백업을 복구할 수 없습니다. 두 가지 옵션이 있습니다.

  • 휴대폰에서 복구: 코드가 여전히 앱에 저장되어 있으면(설정 - 클라우드 백업 확인) 안전한 위치에 복사하여 저장합니다.
  • 새로 생성: 클라우드 백업을 비활성화하고 다시 활성화합니다. 그러면 새로운 복구 코드가 생성되고 기존 백업이 삭제됩니다. 새로 시작합니다.

어디에 보관합니까

복구 코드는 마스터 비밀번호만큼 민감합니다. 다음과 같은 방법으로 저장합니다.

  • 비밀번호 관리자: Bitwarden, 1Password, Apple Keychain 또는 유사한 서비스입니다. 가장 편리한 옵션입니다.
  • 물리적 백업: 종이에 작성하여 금고, 안전 금고 또는 집의 안전한 위치에 보관합니다.
  • 오프라인 문서: 암호화된 외부 드라이브 또는 USB에 저장합니다(클라우드 동기화 불가).
  • 피해야 할 것: 이메일, 노트 앱, 암호화되지 않은 클라우드 서비스 또는 스크린샷입니다.

코드 다시 생성

복구 코드가 손상되었다고 생각하면 클라우드 백업을 끄고 다시 켭니다. 앱이 새로운 복구 코드를 생성합니다. 기존 암호화된 백업이 삭제됩니다. 이는 의도적입니다. 복구 코드 회전은 의도적으로 드물고 손실이 많으므로 신중하게 수행합니다.

면책조항: 복구 코드는 귀하의 책임입니다. Travel Document Vault는 분실한 경우 복구, 리셋 또는 재생성할 수 없습니다. 안전하게 보관합시다. 이 앱을 중요한 문서의 유일한 백업 시스템으로 의존하지 마십시오.
