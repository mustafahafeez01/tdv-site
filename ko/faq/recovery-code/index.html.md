복구 코드는 클라우드 암호화 키를 잠금 해제하는 24자 암호문입니다. 코드 사본을 모두 잃고 보관함을 열 수 있는 모든 기기에 대한 접근까지 잃으면 저희는 백업을 복구할 수 없습니다. 당사는 이를 보유하거나 리셋하지 않으므로 안전한 장소에 보관하십시오.

## 작동 방식

### 복구 코드란 무엇입니까

복구 코드는 PIN을 설정할 때 생성되는 24자리 암호문입니다. 다음과 같이 표시됩니다.

XXXX-XXXX-XXXX-XXXX-XXXX-XXXX

복구 코드는 Pro의 클라우드 백업 복원에 필요한 암호화 키를 잠금 해제합니다. 앱은 PIN을 설정할 때 코드를 생성하여 한 번 표시합니다. 사본을 안전한 곳에 보관하십시오.

### 왜 필요합니까

Pro의 클라우드 백업은 문서 내용을 업로드 전에 기기에서 AES-256-GCM으로 암호화합니다. 복구 코드는 클라우드 암호화 키를 잠금 해제합니다. 백업을 복원하려면 이 코드가 필요합니다. 저희는 사본을 보유하지 않습니다.

저희는 사용자의 클라우드 백업을 대신 복호화하거나 재설정할 수 없습니다. 복구 코드 사본을 모두 잃고 보관함을 열 수 있는 모든 기기에 대한 접근까지 잃으면 저희는 백업을 복구할 수 없습니다.

### 분실했을 경우

복구 코드를 잊었을 때 가능한 조치는 보관함을 열 수 있는 기기와 해당 PIN이 있는지에 따라 다릅니다.

- **휴대폰에서 새 코드 생성:** 클라우드 백업을 켜 둔 채 인터넷에 연결하십시오. 설정, 보안, 복구 코드를 열고 확인한 뒤 PIN을 입력하십시오. 새 코드를 안전한 곳에 보관하고 코드 저장 확인을 눌러 활성화하십시오. 다시 연결하거나 동기화하라는 안내가 나타나면 따르십시오.
- **휴대폰도 분실한 경우:** 복구 코드 사본도 보관함을 열 수 있는 다른 기기도 없다면 저희는 기존 백업을 열 수 없습니다. 새 휴대폰에서 클라우드 백업을 켜고 새로 시작하기를 선택하십시오.

### 어디에 보관합니까

복구 코드는 마스터 비밀번호만큼 민감합니다. 다음과 같은 방법으로 저장합니다.

- **비밀번호 관리자:** 신뢰할 수 있는 비밀번호 관리자를 사용하십시오.
- **물리적 백업:** 종이에 작성하여 금고, 안전 금고 또는 집의 안전한 위치에 보관합니다.
- **오프라인 문서:** 암호화된 외부 드라이브 또는 USB에 저장합니다(클라우드 동기화 불가).
- **피해야 할 것:** 이메일, 노트 앱, 암호화되지 않은 클라우드 서비스 또는 스크린샷입니다.

### 코드 다시 생성

복구 코드가 유출되었다고 생각하면 클라우드 백업을 켜 둔 채 인터넷에 연결하십시오. 설정, 보안, 복구 코드를 열고 확인한 뒤 PIN을 입력하십시오. 앱이 표시한 새 코드를 보관하고 코드 저장 확인을 눌러 활성화하십시오. 다시 연결하거나 동기화하라는 안내가 나타나면 따르십시오.

**면책조항:** 복구 코드는 귀하의 책임입니다. Travel Document Vault는 분실한 코드를 대신 복구하거나 리셋할 수 없습니다. 안전하게 보관합시다. 이 앱을 중요한 문서의 유일한 백업 시스템으로 의존하지 마십시오.
