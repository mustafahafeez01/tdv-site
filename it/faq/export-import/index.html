Come esportare e importare il Vault

L’esportazione del caveau e l’importazione del backup sono gratuite per tutti. Esporti i dati supportati del vault in un file crittografato e protetto da password (.tdvault), entro il limite di dimensioni. Poi lo importi su un altro dispositivo iOS o Android supportato, seguendo i passaggi qui sotto.

Perché esportare e importare?

Esporti il caveau e importi il backup quando cambi telefono o vuoi tenere un backup indipendente. Il file contiene i dati supportati del vault, gli allegati disponibili e alcune impostazioni. Dopo l’importazione controlla documenti e promemoria: il blocco dell’app e le altre impostazioni del dispositivo restano locali.

Il file esportato è crittografato con la stessa sicurezza del Vault locale. Chiunque conosca la password di esportazione può decifrarlo, quindi tienila riservata.

Guida passo dopo passo

1

Aprire Impostazioni e navigare verso Esporta

Avvia Travel Document Vault e tocca l'icona Impostazioni (l'ingranaggio) in fondo allo schermo. Scorri fino alla sezione Backup e dati e tocca Esporta vault.

2

Crea una password per l’esportazione

L’app ti chiede di creare una password per proteggere il backup. Scegline una di almeno 8 caratteri, digitala di nuovo per confermarla e conservala al sicuro. Ti servirà per importare il file: il PIN o il codice di recupero non lo aprono.

3

Attendere il completamento della crittografia

L’app crittografa i dati supportati del vault e gli allegati disponibili in un unico file di backup (.tdvault). Non chiudere l’app durante questo passaggio.

4

Scegliere una destinazione e salvare

Si apre il menu di condivisione del telefono. Scegli dove salvare il file: iCloud Drive, Google Drive, Dropbox o il computer. Per la massima sicurezza consigliamo un servizio crittografato o un archivio offline.

5

Trasferire il file al nuovo dispositivo (se importa su un altro telefono)

Se importi su un dispositivo diverso, rendi il file raggiungibile da lì. Caricalo su un’unità condivisa, mandalo a te stesso via email o usa AirDrop. La dimensione del file dipende dal vault e dal numero di allegati, fino a un limite di 500 MB per esportazione.

6

Sul dispositivo di destinazione, aprire Impostazioni e toccare Importa backup

Avvia Travel Document Vault sul dispositivo su cui vuoi importare. Vai su Impostazioni, scorri fino a Backup e dati e tocca Importa backup. L'app ti chiede di scegliere il file di backup esportato (.tdvault).

7

Selezionare il file esportato e confermare

Trova il file del vault esportato e selezionalo. L’app ti avvisa che l’importazione sostituisce tutti i dati su questo dispositivo. Tocca Importa per procedere, poi inserisci la password impostata durante l’esportazione. L’app decrittografa e importa i profili, i documenti e gli allegati inclusi nel backup.

8

Verificare che tutti i dati siano presenti

Dopo l'importazione, apri la scheda Famiglia e controlla che ci siano tutti i profili. Apri qualche documento per verificare che gli allegati siano intatti. L’importazione sostituisce tutti i dati già presenti su questo dispositivo.

Note importanti

  • Sostituisce i dati esistenti: L'importazione cancella prima ciò che si trova sul dispositivo di destinazione. Se lì hai già dei profili, esportali prima di importare.
  • Cosa passa nel file: Il file trasferisce i campi supportati del vault e alcune impostazioni. Gli allegati mancanti o le note illeggibili possono essere lasciati fuori. Controlla documenti e promemoria importati. Il blocco dell’app e le altre impostazioni del dispositivo restano locali.
  • Crittografato in tutto: Il file esportato è crittografato con la password che scegli al momento dell'esportazione, tramite AES-256-GCM con derivazione della chiave PBKDF2. Solo quella password può decifrarlo, quindi conservala in un luogo sicuro: senza, il file non si può recuperare.
  • Consiglio: Tieni il file esportato in un posto sicuro. Se preferisci, eliminalo dopo un'importazione riuscita, oppure conservalo come backup offline.

Disclaimer: L’esportazione del caveau e l’importazione del backup servono a portare i tuoi dati da un dispositivo all’altro. Tieni i file esportati al sicuro e non condividere il backup con nessuno: contiene tutti i tuoi documenti e allegati crittografati.
