Come esportare e importare il Vault

L’esportazione del caveau e l’importazione del backup sono gratuite per tutti. Esporti i dati supportati del vault in un file crittografato e protetto da password (.tdvault), entro il limite di dimensioni. Lo importi su un altro dispositivo iOS o Android supportato seguendo i passaggi qui sotto.

Perché esportare e importare?

Esporti il caveau e importi il backup quando cambia telefono o vuole conservare un backup indipendente. Il file contiene i dati supportati del vault, gli allegati disponibili e alcune impostazioni. Controlli i documenti e i promemoria importati; il blocco dell’app e altre impostazioni del dispositivo restano locali.

Il file esportato è crittografato con la stessa sicurezza del Vault locale. Chiunque conosca la password di esportazione può decifrarlo: la mantenga riservata.

Guida passo dopo passo

1

Aprire Impostazioni e navigare verso Esporta

Avvii Travel Document Vault e tocchi l'icona Impostazioni (simbolo dell'ingranaggio) in fondo allo schermo. Scorra verso il basso fino alla sezione Backup e dati. Tocchi Esporta vault.

2

Crea una password per l’esportazione

L’app Le chiede di creare una password per proteggere il backup. Ne scelga una di almeno 8 caratteri, la digiti di nuovo per confermarla e la conservi al sicuro. Le servirà per importare il file: il PIN o il codice di recupero non lo aprono.

3

Attendere il completamento della crittografia

L’app crittografa i dati supportati del vault e gli allegati disponibili in un unico file di backup (.tdvault). Non chiuda l’app durante questo passaggio.

4

Scegliere una destinazione e salvare

Si apre il menu di condivisione del telefono. Scelga dove salvare il file: iCloud Drive, Google Drive, Dropbox o il computer. Consigliamo un servizio crittografato o archiviazione offline per la massima sicurezza.

5

Trasferire il file al nuovo dispositivo (se importa su un altro telefono)

Se sta importando su un dispositivo diverso, renda il file esportato accessibile lì. Lo carichi su un'unità condivisa, lo invii a se stesso via email o usi AirDrop. Le dimensioni del file dipendono dalle dimensioni del vault e dal numero di allegati, fino a un limite di 500 MB per esportazione.

6

Sul dispositivo di destinazione, aprire Impostazioni e toccare Importa backup

Avvii Travel Document Vault sul dispositivo in cui desidera importare. Vada a Impostazioni, scorra verso il basso fino a Backup e dati e tocchi Importa backup. L'app Le chiede di selezionare il file di backup esportato (.tdvault).

7

Selezionare il file esportato e confermare

Trovi il file del vault esportato e lo selezioni. L’app avvisa che l’importazione sostituisce tutti i dati su questo dispositivo. Tocchi Importa per procedere, poi inserisca la password impostata durante l’esportazione. L’app decrittografa e importa i profili, i documenti e gli allegati inclusi nel backup.

8

Verificare che tutti i dati siano presenti

Dopo l'importazione, controlli la scheda Famiglia per confermare che tutti i profili siano visualizzati. Apra alcuni documenti per verificare che gli allegati siano intatti. Il processo di importazione sostituisce tutti i dati esistenti su questo dispositivo.

Note importanti

  • Sostituisce i dati esistenti: L'importazione cancella prima ciò che si trova sul dispositivo di destinazione. Se ha già dei profili sul dispositivo di destinazione, li esporti prima di importare.
  • Fedeltà round-trip: Il file trasferisce i campi supportati del vault e alcune impostazioni. Gli allegati mancanti o le note illeggibili possono essere omessi. Controlli i documenti e i promemoria importati. Il blocco dell’app e altre impostazioni del dispositivo restano locali.
  • Crittografato in tutto: Il file esportato è crittografato con la password che sceglie al momento dell'esportazione, tramite AES-256-GCM con derivazione della chiave PBKDF2. Solo quella password può decifrarlo, quindi la conservi in un luogo sicuro — senza di essa il file non può essere recuperato.
  • Migliore pratica di backup: Tenga il file esportato in una posizione sicura. Se preferisce, lo elimini dopo un'importazione riuscita, oppure lo conservi come backup offline.

Disclaimer: L’esportazione del caveau e l’importazione del backup sono pensate per la portabilità dei dati. Mantenga i file esportati al sicuro. Non condivida il backup esportato con nessuno, poiché contiene tutti i Suoi documenti e allegati crittografati.
