## Функции доступности

### Поддержка VoiceOver

Travel Document Vault разработан для работы с VoiceOver. В приложении есть подписи для специальных возможностей и сообщения для программы чтения с экрана.

- Описательные подписи для интерактивных элементов
- Правильная иерархия заголовков для простой навигации
- Значимые описания кнопок и управления
- Объявления статуса для важных изменений

### Больший текст (Dynamic Type)

Текст в приложении масштабируется в соответствии с системной настройкой размера текста. Ограничения масштабирования зависят от элемента.

Отрегулируйте размер текста в **Параметры → Доступность → Дисплей и размер текста → Больший текст** на вашем устройстве.

### Тёмный интерфейс

Travel Document Vault поддерживает как светлый, так и тёмный режимы. Приложение автоматически соответствует внешнему виду вашей системы, или вы можете установить предпочитаемую тему в параметрах.

Опции: **Автоматически (системное)**, **Светлая** или **Тёмная**.

### Достаточный контраст

Цвета текста по умолчанию выбраны для читаемого контраста. Высококонтрастные цвета помогают читать при ярком и слабом освещении.

Основной текст хорошо контрастирует с фоном светлой и тёмной тем по умолчанию.

### Статус передаётся не только цветом

Статус документа никогда не передаётся только цветом. Индикаторы статуса используют значки, формы и текстовые метки в дополнение к цвету.

- Зелёные галочки для действительных документов (не только зелёный цвет)
- Значки предупреждения для истекающих документов (не только жёлтый/оранжевый цвет)
- Индикаторы ошибок со значками X (не только красный цвет)

### Сниженное движение

Некоторые анимации учитывают настройку уменьшения движения. Когда она включена, поддерживаемые анимации сокращаются или отключаются.

Включите в **Параметры → Доступность → Движение → Сниженное движение** на вашем устройстве.

## Дополнительные соображения доступности

Цели касания 44pt

Общие стили элементов управления рассчитаны на 44pt в iOS и 48dp в Android; некоторые элементы меньше.

Читаемые шрифты

Системные шрифты с размерами текста, заданными для разных элементов.

Четкие сообщения об ошибках

Основные сообщения об ошибках, например о форме, которую пока нельзя сохранить, озвучиваются в VoiceOver и показываются с понятным объяснением дальнейших действий.
