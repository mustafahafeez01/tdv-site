## Функции доступности

### Поддержка VoiceOver

Каждый экран в Travel Document Vault полностью озвучен с помощью VoiceOver. Навигируйте, сканируйте документы, устанавливайте напоминания и управляйте вашим хранилищем, используя жесты, клавиатуру, шрифт Брайля и голосовой вывод.

- Описательные подписи для всех интерактивных элементов
- Правильная иерархия заголовков для простой навигации
- Значимые описания кнопок и управления
- Объявления статуса для важных изменений

### Больший текст (Dynamic Type)

Весь текст в приложении масштабируется в соответствии с вашими предпочтениями размера текста системы. Увеличьте размер текста до 200% или более, и макет приложения автоматически адаптируется.

Отрегулируйте размер текста в **Параметры → Доступность → Дисплей и размер текста → Больший текст** на вашем устройстве.

### Тёмный интерфейс

Travel Document Vault поддерживает как светлый, так и тёмный режимы. Приложение автоматически соответствует внешнему виду вашей системы, или вы можете установить предпочитаемую тему в параметрах.

Опции: **Система (Авто)**, **Светлый** или **Тёмный**.

### Достаточный контраст

Весь текст и интерактивные элементы соответствуют стандартам контраста WCAG AAA (4,5:1 для обычного текста, 3:1 для большого текста). Цвета с высоким контрастом обеспечивают читаемость при любых условиях освещения.

Наша система цветов обеспечивает коэффициент контраста 15:1+ для основного текста в обеих светлых и тёмных темах.

### Не только цвет

Важная информация никогда не передаётся только цветом. Индикаторы статуса используют значки, формы и текстовые метки в дополнение к цвету.

- Зелёные галочки для действительных документов (не только зелёный цвет)
- Значки предупреждения для истекающих документов (не только жёлтый/оранжевый цвет)
- Индикаторы ошибок со значками X (не только красный цвет)

### Сниженное движение

Все анимации и эффекты движения уважают вашу настройку сниженного движения. Когда это включено, анимации минимизируются или удаляются, чтобы предотвратить укачивание и дискомфорт.

Включите в **Параметры → Доступность → Движение → Сниженное движение** на вашем устройстве.

## Дополнительные соображения доступности

Цели касания 44pt

Все интерактивные элементы соответствуют минимальному размеру целевого касания Apple в 44pt для простого касания.

Навигация клавиатуры

Навигируйте по всему приложению, используя клавиатуру, подключённую к вашему устройству.

Читаемые шрифты

Системные шрифты, оптимизированные для разборчивости при всех размерах.

Четкие сообщения об ошибках

Состояния ошибок объявляются в VoiceOver и отображаются с чётким, действенным текстом.
