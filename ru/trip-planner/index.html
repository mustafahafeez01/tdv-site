Все готовы, с одного взгляда

С Pro проверяйте связанные документы семьи по сохранённым датам поездки с помощью светофора готовности. Смотрите даты истечения. Планируйте, что взять с собой. Знайте всё заранее. Одно приложение, офлайн, для всей семьи.

Бесплатно начать. Учётная запись не требуется. Pro добавляет планировщик поездок и синхронизацию между устройствами через ваш собственный iCloud или Google Drive.

Как работает планировщик путешествий

Пять функций, которые снимают стресс с планирования семейного путешествия.

Светофор готовности

Зелёный означает, что связанные документы прошли заданные вами проверки для сохранённых дат поездки. Жёлтый отмечает то, что стоит проверить.

Каждый член семьи получает свой собственный статус готовности на основе дат истечения документов и контекста путешествия.

Члены семьи

Видите статус каждого члена семьи с одного взгляда и нажмите, чтобы проверить его документы — знайте, чей паспорт истекает первым.

Построено для семей с 2 - 10+ членами. Работает для супругов, детей, бабушек и дедушек и всех остальных, с кем вы планируете.

Контрольный список упаковки

Список вещей для отдыха или деловой поездки, пункты которого вы отмечаете, собирая багаж, — чтобы не забыть переходник для розетки.

Списки начинаются с шаблона для отдыха или деловой поездки; для каждой поездки можно добавлять и убирать пункты.

Знайте перед отправкой

Панель направления с валютой, языком, типом розеток, напряжением и стороной дорожного движения для популярных направлений — без сюрпризов по прибытии.

Охватывает почти 60 самых популярных направлений; данные встроены в приложение и доступны без интернета.

Квоты дневных лимитов по странам

Отслеживайте, сколько дней каждый член семьи провел в стране, создавая периоды (окно визы или налоговый год) и связывая с ними правила квот — затем посмотрите разбивку по члену семьи с одного взгляда.

Задайте фиксированное или скользящее окно для каждой страны со своим лимитом дней для визы или резидентства. Проверяйте официальные правила отдельно. Использованные дни обновляются автоматически при регистрации путешествий.

И многое другое

Флаг страны + город

Карта путешествия показывает флаг пункта назначения и город. Планируйте с одного взгляда. Знайте, куда вы едите.

Обратный отсчёт дней

Сколько дней до путешествия? Обратный отсчёт появляется на карточках путешествия. Приносит волнение для всех.

Всегда офлайн

Функционирует на 100% офлайн. Планируйте в аэропорту. Интернет не требуется. Работает в режиме полёта.
